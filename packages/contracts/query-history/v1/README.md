# Independent typed-query history observation, version 1

`synthetic-response.json` is a complete recognized grammar vector for the independently versioned `healthmd.history_assessment/1` extension inside existing query-response `metadata`. Client and human/MCP renderer tests consume packaged copies of the same vector in each crate's `src/test-fixtures/history-assessment-v1.json`; the hosted portable gate byte-compares every copy to this canonical file. Copies keep extracted source-archive tests self-contained without a new dependency or divergent validator. It is **synthetic**: placeholder digests are not a dataset/capture receipt, and no physical permission or boundary-equality behavior is established.

This extension does not change the query request/response/status versions, packet metadata, public export schema, metric authority, capture coverage, daily/archive bytes, or raw/file protocols. Receipt fields themselves are never truncated to meet presentation/page bounds. Unknown versions remain opaque; absence is legacy/unassessed. Generic presenters without authenticated request/source context must remain conservative even for a structurally complete vector.
