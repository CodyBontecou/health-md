# Owner-only public account dashboard — deployment contract

`https://healthmd.app/dashboard` is a **temporary redirect** to `https://account.healthmd.app/dashboard`. The static Vercel website must never proxy browser cookies, credentials, exports, or account API requests; its third-party scripts do not run on the isolated account hostname. The same-origin account dashboard has no third-party assets or analytics, uses a strict CSP and a Secure, HttpOnly, SameSite=Strict host-only session cookie. The owner explicitly accepted username/password without MFA for this unbacked single-user pilot; public signup, OAuth, password recovery, and other users are **not** enabled. Do not present this as a general production launch.

The public administration listener runs on loopback **18791**, behind its own nginx loopback proxy **18792**, Tunnel identity, hostname and DNS record. It uses the writer's account database and encrypted-object keys; it is **not** a separately privileged reader like MCP. Its adapter's positive route/method list excludes `POST /api/v1/exports`, signup, raw files, arbitrary paths and MCP. The iPhone writer remains tailnet-only on **18788** and synthetic preview remains upload-disabled on **18787**; do not change the unrelated port 443 route. The MCP reader keeps its distinct read-only OS identity, credentials and public `mcp.healthmd.app` ingress. Reuse neither the MCP Tunnel credential nor its service-account secrets for administration.

The owner may list/download stored exports, page older export and day metadata, manage write-only upload tokens, sign out, request account deletion after password re-entry, and create/revoke per-agent read tokens. Issuance requires password re-entry and explicit full-export consent for that named agent; new tokens last 1–90 days, are returned only once and cannot be recovered. The reader enforces account scope and revocation at every request. **Existing aggregate-only Muse credentials remain aggregate-only**; no rotation or Grokbot credential is implied. The owner must review the specific provider's retention and handling before copying a credential into its secure store. Do not paste tokens into prompts, URL parameters, chat, logs or tickets. This is still an unbacked pilot: VM/disk/key loss can erase everything permanently. Uploads are limited by quota; unlimited revision retention means time, not space or recoverability.

**Source-only examples:** `healthmd-account-dashboard.service.example`, `healthmd-account-proxy.conf.example`, `healthmd-account-proxy.service.example`, `healthmd-account-tunnel.service.example`. The account server fails startup unless its separate origin is exactly `https://account.healthmd.app`, the private writer origin is the existing `*.ts.net:18788` HTTPS endpoint, the explicit loss acknowledgement is present and port 18791 is configured. The account proxy must suppress request/error logs and disable disk buffering; Tunnel ingress must match only the account hostname and otherwise return 404. The public domain should serve no account page or API before origin and endpoint tests pass. Use a dedicated Tunnel and proxied DNS record, never the Vercel origin or public writer route. Cloudflare terminates TLS and may process authorized requests.

Before activating: review current live source/migration hashes and DB integrity with writer and MCP temporarily paused if any migration is needed; install bundles with owner-only permissions and no secrets in source; test the account listener and proxy locally with synthetic requests, including denied public ingest and wrong-host/Origin attempts; confirm public account unauthenticated `/api/agent-tokens` and `/api/exports` return 401, public `POST /api/v1/exports` returns 404, authenticated responses have `no-store`, and old aggregate credentials still list exactly six MCP tools. Validate a disposable full-export credential on public MCP, revoke it and confirm 401 without printing health data. Confirm writer, reader, proxy, Tunnel and unrelated website still work. Route the Vercel `/dashboard` redirect **only after** the dedicated dashboard is live; update public privacy/terms and translations to acknowledge opt-in retained exports before public release.

CLI parity is staged. The CLI and its portable MCP query the foreground iPhone for typed responses and can capture a broader raw corpus. This cloud endpoint only queries **retained API-export JSON**; it cannot query the phone, synthesize missing records, or ingest Android Raw API Snapshot artifacts. Preserve distinct truthful profiles and versioned public contracts before adding shared query names or claiming equivalent coverage. No new mobile sync or expanded data collection is authorized by this dashboard deployment.
