      Phone uploads Write only

      In Health.md, choose Export → API Endpoint. Use this URL and a separate write-only token. Start with one Summary day.

      Copy the token immediately. It cannot read your exports and is shown only once. The app saves it in Keychain. Never put it in the URL.

      Export tokens

        Agent access Read only

        Connect a compatible agent to https://mcp.healthmd.app/mcp with its own Bearer credential. Each new credential can read every retained export JSON field, including historical revisions, free text, embedded source archives and binary data. It cannot access data your device never uploaded. The agent provider may retain or use returned data under its own policies.

        Existing aggregate-only credentials stay restricted. Revoke a credential at any time; it cannot upload or delete exports.
