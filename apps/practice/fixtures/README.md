# Synthetic fixture policy

The executable deterministic fixture catalog is `../src/synthetic/catalog.ts` so Worker, browser, and tests consume the same typed values. Every identity and practice is an obvious fictional alias and every reading/date is generated for interface testing. The hostile markup-shaped fictional label verifies escaped rendering and must never execute or create a network request.

Do not add real names, dates of birth, MRNs, practice identities, URLs, credentials, screenshots, exports, or anecdotes. Protocol identifiers remain the unapproved drafts `1.0-draft.4` and `practice-bp-common/1.0-draft.1`.
