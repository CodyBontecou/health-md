v3.5.6 — Stability fixes
• Fixes a crash after updating or restarting your phone when a scheduled export uses a long custom template.
• Run now no longer crashes and waits for the automation switch to finish.
• Large exports no longer freeze the app or run out of memory.
• JSON exports no longer crash on an invalid value.
• Fixes a crash when closing a schedule picker.
• Scheduled exports work again for automations set up before 3.5.2. If one shows Paused, switch it back on.
