# Wear OS Play screenshot previews

These 400×400 PNGs are review previews captured from the current Health.md Wear OS
`1.8.1` debug build on the API 34 small-round Wear emulator. The dashboard uses the
same synthetic aggregate values as the repository's Wear emulator smoke test. The
Tile image is the installed Daily Activity Tile rendered by the Wear OS system host.

- `1-wear-app-dashboard-emulator-preview.png`
- `2-wear-activity-tile-emulator-preview.png`

The images contain only the app/Tile interface: no device frame, marketing copy,
mask, added background, or production health data. They are design-review assets,
not release evidence and not approved for upload.

Final Play assets remain `../screenshots/wear-app.png` and
`../screenshots/wear-tile.png`. Per that directory's policy, they must be untouched
physical-watch framebuffers captured from the exact Play-generated release APK with
the required signing, reviewer, and evidence receipts.
