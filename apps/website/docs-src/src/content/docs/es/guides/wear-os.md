## Estado actual

- Google Play instala actualmente solo la aplicación de Health.md para el teléfono.
- La aplicación del teléfono no anuncia una función Wear, no ejecuta la sincronización de Data Layer ni muestra ajustes de Wear.
- El módulo del reloj permanece en el código fuente como una vista previa sin publicar.

## Objetivo

Wear está previsto para el ciclo de validación de Android 1.10.0. Solo se publicará después de que las compilaciones exactas firmadas por Play superen pruebas físicas en Pixel Watch y Samsung Galaxy Watch, pruebas de batería, instalación, actualización y reconexión, revisión de capturas y aprobación independiente.

Mientras tanto, usa la aplicación Android del teléfono para exportaciones de Health Connect, programación, widgets y vinculación con Direct CLI.
