---
title: "의료진 보고서"
description: "iPhone 또는 Android에서 데이터 범위를 명확히 밝히는 비공개 설명형 PDF를 Health.md 클라우드 없이 만듭니다."
---

Clinician Report는 포함 범위를 PDF로 만들고 사용자가 미리 본 뒤 명시적으로 공유합니다. 읽기, 정규화, 렌더링은 기기에서 수행됩니다.

<div class="availability available"><strong>iPhone 및 Android에서 제공</strong><p>설정 → Clinician Report를 엽니다. 예약 내보내기 형식이나 Mac 보고서가 아닙니다.</p></div>

1. 최근 7, 30, 90일 또는 사용자 지정 범위를 선택합니다.
2. 측정 항목과 요약 또는 상세 표를 고릅니다.
3. 보고서에서만 쓰는 표시 이름을 선택적으로 입력합니다.
4. 미리 본 뒤 공유하거나 저장합니다.

11개 영역은 혈압, 심박수·안정 시 심박수, 체중, 혈당, 산소, 호흡수, 체온, 수면, 걸음 수, 운동입니다. 보고서는 범위를 유지하며 데이터 누락을 사건이 없었다는 뜻으로 바꾸지 않습니다.

진단, 위험 점수, 치료 권고를 제공하지 않습니다. 신뢰할 수 있는 혈압 쌍만 포함합니다. 임시 파일은 공유 전까지 비공개입니다.
