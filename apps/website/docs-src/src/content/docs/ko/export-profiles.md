내보내기 프로필은 반복 가능한 내보내기 구성을 한데 보관합니다. iPhone 또는 Android의 Health.md에서 관리하세요. Apple 플랫폼에서는 현재 관리 흐름이 iPhone에서만 문서화되고 테스트되었으며, iPad나 Mac용 관리 화면은 제공된다고 주장하지 않습니다.

## 프로필 관리 및 편집

**설정 → 내보내기 프로필**을 여세요. 목록은 활성 프로필을 표시하며 프로필을 생성, 이름 변경, 복제, 삭제, 활성화하거나 살펴볼 수 있습니다. 상세 화면에서 안정적인 ID를 복사할 수 있습니다. 마지막 남은 프로필은 삭제할 수 없습니다.

내보내기 탭에서 변경한 설정은 활성 프로필에 반영됩니다. 현재 프로필을 수정하지 않으려면 설정을 바꾸기 전에 다른 프로필을 활성화하세요.

각 프로필은 실행을 재현하는 데 필요한 선택을 고정합니다.

- 선택한 측정 항목, 데이터 세부 정보, 형식, 템플릿, 파일 이름, 단위 및 쓰기 동작
- 플랫폼이 지원하는 자체 대상 폴더와 하위 폴더, API 엔드포인트 또는 연결된 Mac 대상
- 일일 노트, 개별 항목, 롤업 및 플랫폼이 지원하는 기타 출력 옵션

예약은 프로필의 안정적인 ID에 별도로 연결됩니다. 활성 프로필을 바꿔도 해당 예약의 대상은 바뀌지 않습니다. 프로필 실행은 다른 프로필에서 변경된 설정을 가져오지 않고 저장된 스냅샷을 사용합니다.

## 안전하게 실행 및 예약

- 각 프로필은 앱이 제공하는 사용자 지정 주기를 포함해 자체 반복 예약을 가질 수 있습니다.
- 플랫폼별 구매 조건은 계속 적용됩니다. Apple 무료 한도에는 예약 작업이 포함될 수 있지만 Android 예약에는 평생 구매가 필요합니다.
- 같은 대상에 같은 생성 경로를 쓸 가능성이 있는 프로필은 Health.md가 경고합니다. 경고가 프로필이나 예약을 자동으로 변경하지는 않습니다.
- 중지 또는 취소는 현재 시도에만 영향을 줍니다. 완료된 날짜는 그대로 유지되고, 미해결 날짜는 다시 시도할 수 있으며, 반복 예약은 계속 활성화됩니다.
- 참조한 프로필이 없으면 Health.md는 안전하게 실패하며 활성 프로필이나 다른 대상으로 대체하지 않습니다.

## 이름, 안정적인 ID 및 자동화

표시 이름은 사람을 위한 것이며 변경할 수 있습니다. 안정적인 ID는 이름 변경에도 유지되는 자동화에 사용합니다. **설정 → 내보내기 프로필 → 프로필 ID**에서 복사하세요.

- Apple 단축어는 표시 이름으로 프로필을 선택합니다. 프로필 매개변수가 비어 있으면 활성 프로필을 사용합니다.
- Android의 Tasker 및 adb 브로드캐스트는 안정적인 ID 또는 이름을 `PROFILE` extra로 전달할 수 있습니다. 이름 변경 후에도 유지되어야 하는 흐름에는 ID를 권장합니다.
- Direct CLI는 지원되는 생성 파일 작업에서 `--profile PROFILE_ID`를 받습니다. 프로필은 고정된 출력 설정을 제공하고, 필수 `--destination`은 계속 컴퓨터의 기존 폴더를 선택합니다.

무인 워크플로를 활성화하기 전에 플랫폼 자동화 가이드를 확인하세요.

## 기록, 복구 및 개인정보 보호

프로필 인식 예약 실행과 자동화의 기록 행에는 실행 당시 프로필이 저장됩니다. 기록에는 실제 대상의 개인정보 보호 레이블도 남습니다. 내보내기 탭의 수동 실행은 활성 프로필 설정을 사용하더라도 프로필 이름이 붙지 않을 수 있습니다. 나중에 프로필 이름이나 대상을 바꾸거나 다른 프로필을 선택해도 기존 기록은 다시 작성되지 않습니다.

내보내기 기록에서 시작한 재시도는 현재 구성된 설정과 대상을 사용하고 실제 사용 내역으로 새 행을 기록합니다. 원래 프로필이 재시도를 제어했다고 표시하지 않습니다. 반면 미해결 예약 시도를 복구하거나 재개할 때는 해당 시도의 정확한 날짜, 설정 및 대상을 유지합니다.

프로필과 예약은 기기 로컬 설정입니다. iPhone, iPad, Mac 및 Android 사이에서 동기화되지 않습니다. 각 기기에서 필요한 구성을 다시 만들고 자동화를 활성화하기 전에 대상을 확인하세요.
