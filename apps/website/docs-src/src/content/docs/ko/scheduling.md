이 페이지는 iPhone 예약을 설명합니다. Android는 백그라운드 권한과 구매 조건이 다릅니다. [Android 자동화](/ko/docs/android/)를 참고하세요.

## 첫 예약 내보내기 확인

1. 사용할 프로필을 활성화하고 지표, 형식, 데이터 상세 수준, 쓰기 방식과 대상을 확인합니다. 자동화 전에 완료된 하루를 수동으로 내보내 저장 파일이나 엔드포인트 결과를 확인하세요.
2. 예약에서 설정 또는 관리를 엽니다. 예약을 켜고 매일, 매주 또는 사용자 지정을 선택한 뒤 시각과 완료된 하루의 조회 범위부터 설정합니다. 로컬 복구 알림이 필요하면 알림을 허용하세요.
3. 활성 상태, 다음 실행과 마지막 결과를 확인합니다. 예약된 내보내기가 시도된 후에는 내보내기 기록의 세부 정보와 파일 또는 데이터를 받기로 한 실제 대상을 함께 검사하세요. 다음 시각이나 알림만으로 데이터 기록 완료가 증명되지는 않습니다.
4. 날짜, 단위, 범위와 누락 데이터를 확인하세요. 파일 저장만으로 원본 수집이 완전하다고 볼 수는 없습니다.

Apple에서는 날짜를 하나 이상 내보낸 예약 요청이 수동 등과 같은 무료 내보내기 5회 한도를 사용합니다. Full Access는 이 공통 한도를 없앱니다. [잠금 해제 및 구매](/ko/docs/paywall/)를 참고하세요.

## 완료된 날짜 범위 이해

매일, 매주, 사용자 지정 예약에 과거 조회 범위를 설정할 수 있습니다. 사용자 지정은 시작일부터 N일, 주 또는 개월마다 반복됩니다. 새 실행마다 이미 내보낸 날짜를 포함해 설정된 완료일 범위 전체를 다시 내보냅니다. 예를 들어 조회 범위를 3일로 설정하면 어제와 그 이전 이틀을 내보냅니다. 실행이 늦어지더라도 실제로 앱을 연 날짜가 아니라 원래 예정된 실행일을 기준으로 이 날짜 범위를 계산합니다.

오늘 새로 고침은 당일의 별도 작업이며 이 범위를 대체하지 않습니다. 겹치는 내보내기에서는 경로와 쓰기 방식을 확인하고 같은 날의 반복 스냅샷을 새로운 측정값으로 더하지 마세요.

## 올바른 복구 경로 선택

- **대기 중 예약 복구:** iPhone 잠금을 풀고 Health.md를 열어 해당 시도를 확인합니다. 정확한 미해결 날짜, 저장된 설정과 대상이 유지됩니다. 완료 날짜는 완료로 남고 복구가 조회 범위를 늘리지 않습니다.
- **기록에서 재시도:** 현재 구성된 내보내기 설정과 대상 위치를 사용하여 기록에 표시된 날짜 범위의 새로운 내보내기를 시작하고, 별도의 새 기록 행을 만듭니다. 누르기 전에 활성 설정을 확인하세요. 고정된 대기 요청을 재개하는 것과 다릅니다.
- **변경되거나 사용할 수 없는 대상:** 접근을 복구하거나 대기 프로필을 확인하세요. 이전 iPhone API 복구가 변경된 엔드포인트나 자격 증명을 자동으로 채택해서는 안 됩니다. 원래 시도가 미해결인 동안 새 재시도를 반복하지 마세요.

복구, 식별자와 대상 규칙은 [내보내기 프로필](/ko/docs/export-profiles/)을 참고하세요.

## iOS가 보장하는 것과 보장하지 않는 것

선택 시각은 목표이며 완료 시각의 보장이 아닙니다. iOS가 백그라운드 실행을 제어하며 기기가 잠겨 있을 때 적용되는 데이터 보호 때문에 HealthKit에서 건강 데이터를 읽을 수 없을 수 있습니다. 백그라운드 요청과 무음 알림도 이 보호를 우회하지 못합니다.

로컬 알림은 권한이 필요하며 목표 시각에 전달된다고 보장되지 않습니다. 알림을 받으면 잠금을 풀고 열어 복구를 시도하세요. 알림이 오지 않으면 Health.md에서 대기 작업과 기록을 확인하세요. 알림이나 경과 시간만으로 성공을 판단하지 말고 실제 결과를 검사하세요.

## 프로필별 일정 및 취소

- 각 프로필은 사용자 지정 주기를 포함한 고유 일정을 유지합니다. 활성 프로필을 바꿔도 다른 일정의 대상은 바뀌지 않습니다.
- 같은 대상에 같은 생성 경로를 쓸 가능성이 있는 프로필에는 충돌 경고가 표시됩니다. 경쟁하는 일정을 활성화하기 전에 확인하세요. Health.md는 프로필을 자동으로 바꾸지 않습니다.
- 중지 또는 취소는 현재 시도만 끝냅니다. 완료 날짜는 유지되고, 미해결 날짜는 재시도할 수 있으며, 일정은 계속 활성화됩니다.
- 각 기록 행은 실행 당시 프로필과 실제 대상의 개인정보 보호 레이블에 고정됩니다.

고정 설정과 대상은 [내보내기 프로필](/ko/docs/export-profiles/)에서 관리하세요.
