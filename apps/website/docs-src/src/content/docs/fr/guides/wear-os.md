## État actuel

- Google Play installe actuellement uniquement l’application Health.md pour téléphone.
- L’application téléphone n’annonce aucune capacité Wear, ne lance pas la synchronisation Data Layer et n’affiche pas de réglages Wear.
- Le module montre reste dans le code source comme aperçu non publié.

## Objectif

Wear est visé pour le cycle de qualification Android 1.10.0. Il ne sera publié qu’après validation des builds exacts signés par Play sur Pixel Watch et Samsung Galaxy Watch, tests de batterie, scénarios d’installation, de mise à niveau et de reconnexion, examen des captures et approbation indépendante.

En attendant, utilisez l’application Android sur téléphone pour les exports Health Connect, les planifications, les widgets et l’association Direct CLI.
