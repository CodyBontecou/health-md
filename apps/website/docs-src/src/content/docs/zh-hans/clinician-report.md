---
title: "临床医生报告"
description: "在 iPhone 或 Android 上创建私密、描述性的 PDF，明确数据覆盖且不经过 Health.md 健康数据云。"
---

Clinician Report 将一个包含首尾日期的范围生成 PDF，由你预览并明确分享。读取、规范化和渲染均在设备上完成。

<div class="availability available"><strong>已在 iPhone 和 Android 提供</strong><p>打开“设置 → Clinician Report”。它不是计划导出格式，也不是 Mac 报告流程。</p></div>

1. 选择最近 7、30、90 天或自定义范围。
2. 选择测量项目及摘要或详细表格。
3. 可选输入仅在本报告中使用的显示名。
4. 预览后分享或保存。

11 个领域包括血压、心率与静息心率、体重、血糖、血氧、呼吸频率、体温、睡眠、步数和锻炼。报告保留覆盖信息，不会把缺少数据说成事件没有发生。

它不诊断、不计算风险，也不建议治疗。血压只纳入可信的成对记录。临时文件在你主动分享前保持私密。
