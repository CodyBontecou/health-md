Health.md 在要求 Full Access 前提供 5 次已完成的导出操作。一次操作可写入多个日期和格式，仍只计一次。手动、计划、快捷指令和直连导出在适用时共享计数。

## 何时显示方案提示

- 新手引导中没有购买页面步骤。
- 首次真实导出预览关闭后，可能显示一次可关闭提示。
- 首次免费导出完成后，引导会提示您查看每日计划，但不会自动启用计划。
- 第三次导出后，可关闭的终身访问提示会显示还剩两次免费操作。免费额度为五次已完成的操作。
- 使用 5 次后，下一个需计数的导出会被阻止。

关闭前期提示不会消耗次数。

## Lifetime 方案

StoreKit 2 提供一次性买断，不是订阅：**Individual Lifetime**、**Family Lifetime**，以及面向符合条件用户的家庭升级。以 Apple 购买面板显示的本地价格为准。Family Lifetime 受 Apple 购买项目共享规则约束。

**恢复购买**会刷新 Apple ID 交易。家庭方案需确认 Apple ID、购买项目共享，以及 Health.md 未在购买记录中隐藏。

| 问题 | 处理 |
|---|---|
| 没有价格 | 检查网络/App Store 后重新打开。 |
| 第 5 次前显示 | 这是可关闭提醒，不是最终阻止。 |
| 计划任务暂停 | 购买或恢复后使用正常恢复流程。 |
