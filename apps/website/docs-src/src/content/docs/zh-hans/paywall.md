## 价格
<ul>
<li>Full Access 是一次性 StoreKit 购买项目，价格显示在 App Store 购买表单中。</li>
<li>无需订阅，也不会产生周期性费用。</li>
<li>购买前，Apple 会显示当前本地价格。</li>
<li>无需服务器端账户。解锁与您 Apple ID 的 StoreKit 交易绑定。</li>
</ul>

## Full Access 解锁的功能
<ul>
<li>无限导出。</li>
<li>计划后台导出。</li>
<li>Mac 目标位置工作流。</li>
<li>快捷指令意图。</li>
</ul>

## 恢复之前的购买
<p>在付费墙上轻点<em>恢复购买</em>。应用会通过 StoreKit 查询与当前登录 Apple ID 关联的历史购买记录。重新安装应用或更换新设备后，请使用此方式恢复购买。</p>

## 退款与支持
<p>退款由 Apple 处理——请前往 <a href="https://reportaproblem.apple.com">reportaproblem.apple.com</a> 提交申请。如需应用支持，请发送邮件至 <a href="mailto:cody@isolated.tech">cody@isolated.tech</a>。</p>
