Clinician Reportは指定期間をPDFにし、利用者がプレビューして明示的に共有します。読み取り、正規化、生成は端末内で行われます。

<div class="availability available"><strong>iPhoneとAndroidで提供中</strong><p>設定 → Clinician Reportを開きます。スケジュール形式やMacレポートではありません。</p></div>

1. 7、30、90日または任意期間を選びます。
2. 測定項目と概要または詳細表を選びます。
3. 任意の表示名を入力します。保存やファイル名には使いません。
4. プレビューして共有または保存します。

11領域は血圧、心拍数・安静時心拍数、体重、血糖、酸素、呼吸数、体温、睡眠、歩数、ワークアウトです。データ範囲を保持し、欠測を「出来事がなかった」とは表現しません。

診断、リスク計算、治療提案は行いません。血圧は信頼できるペアだけを含めます。一時ファイルは共有操作まで非公開です。
