title: "輸出"

---

<p> [エクスポート] タブは、準備の確認、宛先の選択、プレビューまたはエクスポート前の日付範囲の選択という 3 つの小さな決定で構成されています。 </p>

## ステータス バッジを読み取ります
 <div class="options">
 <div class="option"> <strong>ヘルス バッジ</strong> <p>緑色はアプリの接続済みの設定状態を示します。すべてのカテゴリの読み取り権限が確認されたことを意味しません。HealthKitは読み取り権限の拒否をアプリに知らせません。バッジをタップしてアクセスを要求します。未選択のデータ型にはiOSの許可画面が表示される場合があります。選択が記録済みの場合、Health.mdは権限の案内を表示します。Apple Healthでカテゴリを確認してください。空の結果はアクセス拒否または該当データがないことを意味する場合があります。<a href="/ja/docs/troubleshooting/">データが見つからない場合の確認</a>。</p> </div>
 <div class="option"> <strong> Vault バッジ</strong> <p>緑色の点 = Vault フォルダが選択されています。タップしてボールトを再選択または変更します。ラベルにはフォルダー名が表示されます。 </p> </div>
 </div>
 <p>エクスポート<em>アクションは</em> HealthKit 、出力形式、および選択した宛先が準備できるまで無効のままです。これにより、宛先を指定せずにエクスポートしようとするという最も一般的な失敗モードが回避されます。 </p>

## エクスポート ターゲットを選択します
 <p>エクスポート ターゲット カードによってデータの保存先が決定されます: </p>

<div class="options">
 <div class="option"> <strong>ローカルiPhoneフォルダー</strong> <p>このデバイス上で選択したフォルダーまたはObsidianコンテナーに直接書き込みます。 </p> </div>
 <div class="option"> <strong>接続された Mac </strong> <p>キャプチャされた毎日のデータと正確な設定のスナップショットを近くの Mac アプリに送信します。 iPhoneはHealthKitと読み取られます。 Mac は選択した形式をレンダリングし、ファイルを書き込みます。 </p> </div>
 <div class="option"> <strong> API エンドポイント</strong> <p> iPhoneからユーザーが構成した HTTP(S) エンドポイントに JSON エンベロープを直接 POST します。 <a href="/ja/docs/api-endpoint/"> API エンドポイント</a>を参照してください。 </p> </div>
 </div>

## 日付範囲を選択します
 <p>日付プリセットは共通パスをカバーします: </p>

<div class="options">
 <div class="option"> <strong>今日</strong> <p>現在の日をエクスポートします。出力フォーマットをテストするのに役立ちます。 </p> </div>
 <div class="option"> <strong>昨日</strong> <p>その日は完了しているため、最も安全な日次エクスポートの選択です。 </p> </div>
 <div class="option"> <strong>常時</strong> <p> Health.mdが見つけた最も古いHealthKitデータからバックフィルします。 </p> </div>
 <div class="option"> <strong>カスタム</strong> <p>特定の範囲の開始日と終了日を選択します。 </p> </div>
 </div>

## プレビューまたはエクスポート
 <div class="options">
 <div class="option"> <strong>プレビュー</strong> <p>何かが書き込まれる前に生成されるファイルとコンテンツを表示します。 </p> </div>
 <div class="option"> <strong>エクスポート</strong> <p>エクスポートを実行し、メイン画面に進行状況を表示し、結果を履歴に記録します。 </p> </div>
 </div>

## データの詳細レベルを選択します

<div class="options">
 <div class="option"> <strong>概要</strong> <p>読み取り、メモ、ダッシュボード用のコンパクトな日次合計とロールアップ。 </p> </div>
 <div class="option"> <strong>詳細な時系列</strong> <p>選択されたタイムスタンプ付きサンプルと間隔。このレベルは、選択したメトリクスが適切な詳細を明らかにする場合、Apple と Android の両方で利用できます。 </p> </div>
 <div class="option"> <strong>ロスレス健康記録</strong> <p>正規のHealthKitソースレコード アーカイブ。このレベルは Apple のみです。 Android はHealth ConnectレコードをHealthKitアーカイブに変換しません。 </p> </div>
 </div>

## 「エクスポート」の実際の内容
 <ol>
 <li>範囲内の毎日について、選択した概要予測を取得します。詳細時系列に互換性のあるサンプルを追加します。また、ロスレス健康レコードの場合は、正規のソース レコードとクエリ診断を追加します。 </li>
 <li>選択した形式 ( Markdown 、Bases、JSON、または CSV) とテンプレートを適用します。 </li>
 <li> 1 日あたり 1 つのファイルを<code>{vault}/{subfolder}/</code>に書き込むか、接続された Mac ワークフローを通じてファイルを転送するか、バージョン管理された JSON エンベロープを API エンドポイントに POST します。 </li>
 <li>個別追跡<em>がオンの場合、選択されたエントリごとの</em>ファイルMarkdownファイルベースのターゲットの正規アーカイブから派生します。 </li>
 <em> <li>毎日のメモの挿入</em>がオンの場合、選択した概要フィールドを毎日のメモにマージします。 </li>
 </ol>

<p> JSON と CSV は正規レコードを保存できます。 Markdownと Bases は読み取り可能な状態を維持し、アーカイブを埋め込むのではなく、コンパクトなキャプチャ診断を公開します。正確なスキーマと省略ルールについては、 <a href="/ja/docs/reference/">完全なエクスポート リファレンス</a>を参照してください。 </p>

## 停止、キャンセル、再試行

停止またはキャンセルすると、現在の試行のみが終了します。すでに完了したファイルと日付は完了したままですが、未解決の日付は引き続き再試行できます。スケジュールされた試行をキャンセルしても、その定期的なスケジュールは無効になりません。

## プロフィールと信頼できる経歴

保存されたプロファイルは、その設定と実行の宛先を固定します。プロファイル対応のスケジュールされた自動化履歴行は実行時プロファイルを保持しますが、履歴には実際に使用された宛先のプライバシーに安全なラベルが保持されます。手動の [エクスポート] タブの行では、プロファイル名が省略される場合があります。後で名前を変更したり宛先を変更しても、既存の履歴は上書きされません。欠落しているプロファイル参照は、フォールバックせずにフェールクローズされます。 [プロファイルのエクスポート](/ja/docs/export-profiles/)を参照してください。

## タブバー

<p>画面の下部にある 4 つのタブ (エクスポート、スケジュール、同期、設定) は、アプリの表領域全体をカバーします。他のものはすべて、設定の 1 つまたは 2 つの層の奥に存在します。 </p>

<div class="callout">
 <strong>ロック解除動作。 </strong>
 <p style="margin-top:6px;">サブスクリプション対応のiPhone / iPadおよびGoogle Play電話機リリースには、エクスポートとスケジュールのためのアクティブな試用版、サブスクリプション、ライフタイム、または保存された永続的なアクセスが必要です。現地の自由輸出枠は残っていない。 Mac コンパニオンおよびF-Droid含まれるアクセス ビルドでは、文書化された例外が保持されます。 <a href="/ja/docs/paywall/"> Apple の購入の詳細については、ペイウォール ページ</a>を参照してください。 </p>
 </div>
