## 利用可能なインテント
<div class="options">
<div class="option"><strong>昨日のヘルスデータをエクスポート</strong><p>パラメータなしのショートカットです。「昨日のデータだけをすぐにエクスポートする」ための最短手段で、手動エクスポートと同じエンジンを使用します。</p></div>
<div class="option"><strong>指定日のヘルスデータをエクスポート</strong><p><em>日付</em>パラメータが1つあります。時刻は無視されます。カレンダーを起点とするオートメーションに便利です。</p></div>
<div class="option"><strong>指定期間のヘルスデータをエクスポート</strong><p><em>開始日</em>と<em>終了日</em>のパラメータがあり、両端の日付を含みます。バックフィルに使用します。</p></div>
<div class="option"><strong>過去N日間のヘルスデータをエクスポート</strong><p><em>日数</em>パラメータ（1～366）があります。期間は昨日までで、デフォルトは7です。「毎週日曜日に過去7日間をエクスポートする」といったオートメーションに適しています。</p></div>
<div class="option"><strong>指定日のヘルスサマリーを取得</strong><p>Vaultに何も書き込まず、歩数、アクティブカロリー、睡眠、心拍数を含む構造化スナップショットを返します。ショートカット内で値をほかのアプリへ渡す場合に使用します。</p></div>
<div class="option"><strong>最後のエクスポート状況を取得</strong><p>直近に記録されたエクスポートのタイムスタンプ、成功状態、日数、失敗理由を返します。ロック中のデバイスで行われた要求は再試行されるまで保留となるため、保留中は現在の状況として返されません。</p></div>
<div class="option"><strong>スケジュールされたエクスポートをオン／オフ</strong><p>真偽値パラメータです。たとえば休暇の集中モード中にスケジュールを停止し、後で再開できます。</p></div>
<div class="option"><strong>ヘルスデータをエクスポート</strong><p>汎用エクスポートです。アプリ内のエクスポートモーダルで最後に設定した日付範囲を使用します。通常は、日付範囲が明示されたインテントのほうが分かりやすいため、使用頻度は低めです。</p></div>
</div>

## 見つける方法
<p>iOSまたはmacOSでショートカットアプリを開きます。<em>＋</em>ボタンをタップして新しいショートカットを作成し、「Health.md」または上記いずれかのインテント名を検索します。これらは<em>ヘルスケア</em>カテゴリにあります。</p>
<p>ほとんどのインテントでは<code>openAppWhenRun = false</code>のため、アプリを起動せず、UIを表示することなく実行されます。オートメーション、集中モードフィルタ、Hey Siriのハンドオフ、アクションボタンから利用できます。</p>

<div class="callout">
<strong>ロック中の実行ではHealthKitのロックは解除されません</strong>
<p style="margin-top:6px;">AppleはiPhoneのロック中にHealthKitデータを保護し、<a href="https://support.apple.com/guide/security/protecting-access-to-users-health-data-sec88be9900f/web">ロックから約10分後にアプリからのアクセスを遮断します</a>。<em>ロック中の実行を許可</em>にするとショートカットはアクションを開始できますが、HealthKitのデータ保護を回避することはできません。ショートカットのHealth.mdアプリコンテンツ権限でも、この制限は回避できません。</p>
<p>HealthKitを利用できない場合、Health.mdは要求された日付を保留中として保持し、<em>ヘルスエクスポートに対応が必要です</em>という通知を送信します。iPhoneのロックを解除してから、通知をタップするかHealth.mdを開いて再試行してください。iPhoneがロックされたままでは、完全に無人のエクスポートを保証できません。</p>
</div>

## レシピ：確認付きの日次エクスポート
<ol>
<li><strong>個人用オートメーション</strong> → <em>時刻</em> → 午前8:00など、普段iPhoneのロックを解除して使用している時刻を選択します。</li>
<li><em>昨日のヘルスデータをエクスポート</em>インテント。</li>
<li><em>最後のエクスポート状況を取得</em>インテント。</li>
<li>結果を使って<em>通知を表示</em>します。</li>
</ol>
<p><strong>保留状況に関する注意：</strong><em>最後のエクスポート状況を取得</em>は、エクスポート履歴に直近で記録されたエントリを読み取ります。今回の実行でロック中のHealthKitデータに遭遇した場合、保留中の要求を再試行するまでは以前のエクスポートが表示されることがあります。保留中の処理については、Health.md自身の復旧通知が正確な状態を示します。</p>

## レシピ：一度だけバックフィルする
<ol>
<li>ショートカットを作成します。</li>
<li><em>指定期間のヘルスデータをエクスポート</em>で、start = 2024-01-01、end = 2024-12-31を設定します。</li>
<li>ショートカットから実行します。1年分を処理し、1日につき1ファイルを書き込みます。1年分すべてでは数分かかる場合があります。</li>
</ol>

## レシピ：休暇中にスケジュールを一時停止する
<ol>
<li><strong>集中モードフィルタ</strong>：<em>休暇</em>の集中モードがオンになったら、Enabled = falseで<em>スケジュールされたエクスポートをオン／オフ</em>を実行します。</li>
<li>集中モードがオフになったら、Enabled = trueでもう一度実行します。</li>
</ol>

<div class="callout">
<strong>権限の設定が必要です</strong>
<p style="margin-top:6px;">インテントは、アプリ内のHealthKit権限とVaultの選択を引き継ぎます。このデバイスでアプリを一度も開いて設定していない場合は、明確なエラーを表示して失敗します。</p>
</div>
