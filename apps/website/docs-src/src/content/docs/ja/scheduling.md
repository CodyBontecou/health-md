このページでは、 iPhoneスケジューリングについて説明します。 Android にはさまざまなバックグラウンド権限と購入要件があります。 [Android オートメーション](/ja/docs/android/) を参照してください。

## 最初にスケジュールされたエクスポートを確認する

1. 目的のプロファイルをアクティブ化します。メトリクス、形式、データの詳細、書き込み動作、宛先を確認してください。自動化を有効にする前に、完了した 1 日を手動で実行し、保存されたファイルまたはエンドポイントの結果を検査します。
2. iPhoneでは**オートメーション**を開いてオートメーションを選び、**スケジュール**をタップします。Androidでは「スケジュール」を開き、「スケジュールを設定」または「スケジュールを管理」を選びます。スケジュールを有効にし、毎日・毎週・カスタムから選んで時刻を設定し、まずは完了した1日分を振り返る設定から始めます。ローカルの復旧リマインダーが必要なら通知を許可してください。
3. スケジュールが有効かどうか、次の発生と最後の結果を確認します。試行後、履歴の詳細と実際の宛先を検査します。次回実行ラベルや通知は、データが書き込まれたことを証明するものではありません。
4. エクスポートされた日付、単位、カバレッジ、欠落データを確認します。保存されたファイルだけでは、ソースが完全にキャプチャされたことを証明するものではありません。

サブスクリプション対応の電話リリースでは、スケジュールされたエクスポートと手動エクスポートには、アクティブな試用版、サブスクリプション、生涯購入、または保存された永久アクセスが必要です。現地の自由輸出枠はありません。保留中の作業を再開するには、期限切れのアクセスを復元する必要があります。 [ロック解除とペイウォール](/ja/docs/paywall/)を参照してください。

## 完了日ウィンドウを理解する

毎日、毎週、カスタムのスケジュールをルックバックできます。カスタム ケイデンスは、開始日から N 日、週、または月ごとに繰り返されます。新しいイベントが発生するたびに、以前にエクスポートされた日付を含む、設定された完了日ウィンドウ全体が再エクスポートされます。 3 日間の振り返りには、昨日とその前の 2 日間が含まれます。実行を遅らせると、ウィンドウは予定された火災の日に固定されたままになります。

Today Refresh は、別の当日の作業であり、完了した 1 日のウィンドウに代わるものではありません。エクスポートを重複させる前に、パスと書き込み動作を検査します。繰り返される毎日のスナップショットを新しい測定値として一緒に追加しないでください。

## 正しい回復パスを選択してください

- **スケジュールされたリカバリの保留中:** iPhoneのロックを解除し、 Health.mdを開いて、保留中の試行を検査します。正確な未解決の日付、保存された設定、目的地が保持されます。完了した日付は完了したままになります。回復が新たな振り返りにまで拡大することはありません。
- **履歴から再試行:** 現在構成されている設定と宛先を使用して、その範囲に対して新しい実行が開始され、新しい履歴行が記録されます。 「再試行」を押す前に、アクティブな構成を確認してください。これは、凍結された保留中の試行を再開することと同じではありません。
- **宛先が変更されているか、利用できません:** アクセスを復元するか、保留中のプロファイルを調べてから再試行してください。古いiPhone API リカバリでは、変更されたエンドポイントまたは資格情報をサイレントに採用してはなりません。元の試行が解決されていない間は、新しい再試行を繰り返し開始しないでください。

[プロファイルのエクスポート](/ja/docs/export-profiles/) で保留中の回復、プロファイル ID、宛先ルールを確認します。

## iOS が行うことと保証しないこと

選択した時間は目標であり、完了時間を保証するものではありません。 iOS はバックグラウンド ランタイムを制御し、ロックされたデバイス保護によりHealthKit読み取りを防ぐことができます。バックグラウンド要求とサイレントウェイク通知はその保護をバイパスしません。

ローカルリカバリ通知には通知許可が必要ですが、目標時刻に配信されることを保証するものではありません。受け取った場合は、デバイスのロックを解除して開き、 Health.md回復を試行できるようにします。通知が届かない場合は、 Health.mdを開いて保留中の作業と履歴を確認してください。アラートや経過時間が成功を意味すると考えるのではなく、結果を検証してください。

## プロフィールのスケジュールとキャンセル

- すべてのプロファイルは、カスタム ケイデンスを含む独自のスケジュールを維持できます。アクティブなプロファイルを切り替えても、別のプロファイルのスケジュールは再ターゲットされません。
- プロファイルが同じレンダリングされたパスを同じ宛先に書き込む可能性がある場合、衝突警告が表示されます。競合するスケジュールを有効にする前に確認してください。 Health.mdはどちらのプロファイルもサイレントに変更しません。
- 停止またはキャンセルでは、現在の試行のみが終了します。完了した日付は完了したままになり、未解決の日付は再試行可能のままになり、スケジュールは有効なままになります。
- 各履歴行は、実行時プロファイルと実際に使用されるプライバシーに安全な宛先ラベルに固定されたままになります。

[プロファイルのエクスポート](/ja/docs/export-profiles/) で、凍結された設定とプロファイルごとの宛先を管理します。
