## 価格
<ul>
<li>Full Accessは1回限りのStoreKit購入で、価格はApp Storeの購入シートに表示されます。</li>
<li>サブスクリプションや継続課金はありません。</li>
<li>現在の地域別価格は購入前にAppleが表示します。</li>
<li>サーバー側のアカウントはありません。ロック解除はApple IDのStoreKitトランザクションに紐づきます。</li>
</ul>

## Full Accessで利用できる機能
<ul>
<li>無制限のエクスポート。</li>
<li>スケジュールエクスポート。</li>
<li>Macのエクスポート先。</li>
<li>ショートカットのインテント。</li>
</ul>

## 以前の購入を復元する
<p>ペイウォールで<em>購入を復元</em>をタップします。アプリは、サインイン中のApple IDに紐づく以前の購入をStoreKitに照会します。アプリを再インストールした後や、新しいデバイスへ移行した後は、この方法を使用してください。</p>

## 返金とサポート
<p>返金はAppleを通じて行われます。<a href="https://reportaproblem.apple.com">reportaproblem.apple.com</a>から申請してください。アプリに関するサポートは、<a href="mailto:cody@isolated.tech">cody@isolated.tech</a>までメールでお問い合わせください。</p>
