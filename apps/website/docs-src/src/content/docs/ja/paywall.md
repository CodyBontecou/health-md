title: "ロック解除と購入画面"

---

Health.mdではFull Accessが必要になる前に、完了したエクスポートアクションを10回利用できます。1回のアクションで複数の日付や形式を書き出しても1回です。手動、スケジュール、ショートカット、直接エクスポートは対象時に同じカウンターを使います。

## 案内が表示される時点

- オンボーディング内に購入画面はありません。
- 最初の実データプレビュー後に、一度だけ閉じられる案内が表示される場合があります。
- 3回目と7回目の無料エクスポート後に案内が出る場合があります。
- 10回使用後は、次の対象エクスポートがブロックされます。

早い段階の案内を閉じても回数は消費しません。

## Lifetimeオプション

StoreKit 2による買い切りで、継続サブスクリプションではありません。**Individual Lifetime**、**Family Lifetime**、対象者向けのFamilyアップグレードがあります。Appleの購入シートに表示される現地価格が正です。Family LifetimeはAppleの購入共有に依存します。

**購入を復元**はApple IDの取引を更新します。Familyの場合はApple ID、購入共有、購入履歴でHealth.mdが非表示でないことを確認してください。

| 問題 | 対応 |
|---|---|
| 価格がない | 通信とApp Storeを確認し、画面を開き直します。 |
| 10回前に表示 | 閉じられる案内であり、最終ブロックではありません。 |
| スケジュールが停止 | 購入または復元後、通常の復旧を行います。 |
