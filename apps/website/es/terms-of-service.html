4. Funcionalidad de la Aplicación

health.md está diseñada para:

  • Leer sus datos de Apple Health mediante las API de HealthKit o sus datos de salud de Android mediante las API de Health Connect
  • Exportar esos datos a archivos Markdown, Obsidian, CSV y JSON en los destinos que usted elija
  • Automatizar este proceso de exportación conforme a una programación definida por usted, con sujeción a los límites de ejecución en segundo plano de Apple o al funcionamiento de Android WorkManager
  • Enviar trabajos de exportación directamente a un Mac o una CLI opcionales y emparejados en los flujos de trabajo compatibles
  • Enviar determinadas exportaciones directamente a un punto de conexión API configurado por el usuario

El tratamiento principal de los datos de salud se realiza localmente en sus dispositivos. Health.md no recopila ni almacena datos de salud en los servidores de Health.md. Algunos flujos utilizan conexiones de red dirigidas por usted o servicios de la plataforma, incluidas las compras o restauraciones de App Store o Google Play, las actualizaciones de la aplicación, iCloud, la sincronización con proveedores de documentos de Android o proveedores de archivos de terceros, la transferencia a dispositivos emparejados y un punto de conexión API configurado por el usuario.

5. Exención de responsabilidad sobre datos de salud

IMPORTANTE: health.md es una herramienta de exportación de datos, no un producto sanitario ni un servicio de salud.

  • La Aplicación no ofrece asesoramiento, diagnóstico ni tratamiento médico
  • La Aplicación no sustituye la consulta con profesionales sanitarios cualificados
  • Los datos exportados son exclusivamente para fines informativos personales
  • No verificamos la exactitud de los datos procedentes de Apple Health, Health Connect, dispositivos vestibles o aplicaciones de salud conectadas
  • No utilice los datos de salud exportados para tomar decisiones médicas sin consultar a un profesional sanitario

En caso de emergencia médica, póngase inmediatamente en contacto con los servicios de emergencia. No dependa de datos procedentes de esta Aplicación para tomar decisiones médicas urgentes.
