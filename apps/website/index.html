07 Practical details

Before you connect.

Health.md is a data tool—not a diagnosis service, healthcare provider, or medical device.

Read the full documentation →
01Does Health.md upload my health data?

No. Health.md does not run a health-data cloud or require an account. Reads happen on your devices, and exports move only to destinations you choose.

02What can I automate?

Schedule exports, run Apple Shortcuts, trigger Android Tasker or adb workflows, process local files with scripts, and query data through the CLI or MCP.

03Do I need Obsidian?

No. Obsidian is one supported destination. Markdown, CSV, and JSON work with any folder, notebook, spreadsheet, or script.

04Can an AI agent use it?

Yes. Scoped CLI and MCP tools return factual data with units, coverage, evidence, and missingness. Health.md does not provide medical advice.

05Is there a subscription?

No. Download for free, then unlock unlimited and scheduled exports with a one-time in-app purchase if you need them.
