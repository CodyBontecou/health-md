# A little context for your health data

A free Obsidian starter vault from [Health.md](https://healthmd.app/).

> [!note] Entirely fictional
> Every measurement and journal entry in this vault is made up. No account, purchase, health permission, or community plugin is needed to explore the sample. These values are examples, not targets or medical advice.

## Take a five-minute tour

1. Open [[Health Dashboard]] for four weeks of charts and a day-by-day log.
2. Read [[Reviews/2026-10-19 Weekly review|a completed weekly review]] to see numbers alongside everyday context.
3. Open [[Health/2026-10-08|a day with missing sleep data]]. Notice that missing is different from zero.
4. Make it yours with [[Guides/Use your own data|Use your own data]].

The sample runs from **September 28 to October 25, 2026**. Dates stay fixed so the example remains readable whenever you open it.

## Your small routine

- **During the week:** add a few words of context to a daily note.
- **Once a week:** create a note in `Reviews`, insert [[Templates/Weekly review|Weekly review]], and set the week dates.
- **When something looks unusual:** check the underlying notes and data coverage before drawing conclusions.

## Open this as a vault

Unzip the download, then in Obsidian choose **Open folder as vault** and select **Health.md Starter**. Use Obsidian **1.12 or later** for the included Bases views and optional plugin setup. If this note opens as raw text, switch to Reading view.

The chart images work as soon as the notes open. If the log is blank or shows a `.base` link, enable **Settings → Core plugins → Bases**. To use the templates, enable **Templates** and set its folder to `Templates`.

Everything is stored in this folder. Obsidian sync and backup settings are yours to choose. Optional community plugins require your own installation and approval; none are bundled or enabled here.
