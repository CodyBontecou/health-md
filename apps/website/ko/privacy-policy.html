요약: Health.md는 Health.md 서버에서 건강 데이터를 수집하거나 저장하지 않습니다. HealthKit 및 Health Connect 데이터는 사용자의 기기에서 처리되며 폴더, 파일 제공자, 페어링된 기기 또는 사용자가 구성한 API 엔드포인트 등 사용자가 선택한 대상으로만 전송됩니다. 앱은 타사 분석·광고·기여도 SDK 없이 제한된 자사 제품 분석을 자동 수집합니다. 이러한 이벤트에는 건강 값, 측정 항목 이름, 건강 날짜, 내보낸 콘텐츠, 경로, 피어 이름, 자격 증명 또는 사용자 텍스트가 포함되지 않으며 광고나 앱 간 추적에 사용되지 않습니다.

개인정보 보호에 대한 약속

건강 데이터는 사용자의 것입니다. Health.md는 플랫폼 권한을 받은 뒤에만 이를 읽으며 서버 사본을 보관하지 않습니다. 이 정책은 사용자가 지시하는 내보내기와 전송, 제한된 자사 제품·웹사이트 분석 및 최소화된 자사 캠페인 기여도 측정을 설명합니다.

데이터 수집

내보내기에 Health.md 계정은 필요하지 않으며 건강 데이터를 Health.md 서버로 전송하지 않습니다. 구체적으로:

  • 건강 데이터 내보내기에 계정 생성이나 등록이 필요하지 않습니다
  • Health.md 서비스는 HealthKit 샘플, Health Connect 기록, 내보내기 문서, 타입 지정 쿼리 결과 또는 건강 첨부 파일을 수집하거나 보관하지 않습니다
  • 앱에 타사 분석, 기여도, 충돌 보고, 광고 또는 추적 SDK가 없습니다
  • 제품 분석이나 캠페인 기여도에 Advertising ID, Android ID, 하드웨어 ID, 추적 픽셀, 건강 샘플, 내보내기 콘텐츠 또는 파일·폴더 경로가 포함되지 않습니다
  • 제한된 자사 제품 및 캠페인 데이터는 아래 설명에 따라서만 수집됩니다

자사 캠페인 기여도

Health.md는 타사 기여도 SDK 없이 캠페인의 종합 성과를 측정하기 위해 healthmd.app/v/yt-csv-001 같은 자사 캠페인 링크를 사용합니다. Cloudflare 리디렉션 서비스는 캠페인 토큰, 링크 슬러그, 캠페인 플랫폼과 콘텐츠 관점, 대략적인 대상·클라이언트 범주, 제공된 경우 참조 호스트 이름, 대략적인 국가 코드 및 타임스탬프를 기록합니다. 저장되는 클릭 행에는 IP 주소나 전체 User-Agent가 포함되지 않습니다.

Android에서는 Google Play Install Referrer가 해당 설치를 캠페인과 연결할 수 있습니다. 유효한 캠페인 설치의 경우 앱은 무작위로 생성한 설치 및 이벤트 UUID, 앱 버전과 빌드 번호, 검증된 캠페인 토큰·소스·매체·콘텐츠 메타데이터, 이벤트 시간, 선택적 Play 참조 클릭 및 설치 시작 타임스탬프가 담긴 이벤트 하나를 전송합니다. 무작위 설치 UUID는 해당 설치의 지속적인 가명 식별자이며 기기 또는 광고 식별자에서 파생되지 않습니다. Health.md는 전체 원시 Install Referrer를 저장하거나 전송하지 않습니다.

캠페인 클릭과 기여 설치는 종합 보고를 위해 검증된 캠페인 토큰으로만 결합됩니다. 캠페인 기여도 기록은 최대 13개월 보관됩니다. 종합 수집 속도 카운터에는 1분 단위 구간과 건수만 포함되며 24시간 뒤 삭제됩니다. Cloudflare는 자체 약관에 따라 일반 네트워크 연결 정보를 처리하지만, Health.md는 설치 기여도 기록에 IP 주소, 전체 User-Agent, Cloudflare 요청 ID, 쿠키 또는 지문 정보를 추가하지 않습니다.

자사 제품 분석

Health.md는 타사 분석 SDK 없이 대략적인 온보딩, 활성화, 내보내기, 결제 화면 및 구매 흐름 성과를 파악하기 위해 자사 Cloudflare Worker와 D1 데이터베이스를 사용합니다. 앱은 무작위 설치 UUID와 이벤트 UUID, 이벤트 이름, 앱 버전·빌드·플랫폼, 그리고 관련 허용 목록 필드만 전송합니다. 여기에는 온보딩 단계 또는 명시적 설정 건너뛰기, 무료 내보내기 횟수, 내보내기 대상 범주, 형식 수, 측정 항목 수와 기간 구간, 결제 화면 맥락, StoreKit 또는 Google Play 제품 식별자, 구매·복원 결과, 대략적인 권한 또는 오류 범주가 포함됩니다.

제품 분석에는 HealthKit 또는 Health Connect 값·식별자, 측정 항목 이름, 건강 날짜, 약물, 운동, 내보내기 내용, 타입 지정 쿼리 결과, 폴더·보관함·파일 이름이나 경로, 피어·기기 이름, 계정 데이터, 자격 증명·토큰, 사용자 텍스트, Advertising ID, Android ID, 하드웨어 식별자, 원시 리퍼러, 전체 User-Agent 또는 저장된 IP 주소가 절대 포함되지 않습니다. 알 수 없는 엔벨로프, 이벤트, 속성 및 속성 값 필드는 수집 서비스에서 거부됩니다. 무작위 설치 UUID는 앱 설치 기간 동안 유지되는 가명 식별자이며 기기, 계정, 광고 또는 건강 식별자에서 파생되지 않습니다.

이 제한된 제품 이벤트는 자동 수집되지만 광고주와 공유하거나 광고, 지문 인식 또는 앱 간 추적에 사용하지 않습니다. 공개 클라이언트와 Worker 허용 목록은 건강 기록 및 내보낸 콘텐츠를 분석 페이로드로 표현할 수 없도록 설계되었습니다.

검증된 분석 행은 최대 13개월 보관된 뒤 매일 자동 삭제됩니다. Health.md는 원시 IP 주소, 전체 User-Agent, 요청 URL·헤더, 자격 증명 또는 검증된 이벤트 필드 외의 요청 본문을 분석 행에 추가하지 않습니다. Cloudflare는 자체 약관에 따라 일반 네트워크 연결 정보를 처리합니다.

앱 작동 방식

Health.md는 Apple의 HealthKit API로 Apple Health 데이터를, Health Connect로 Android 건강 데이터를 기기에서 읽습니다. HealthKit 내보내기의 원본은 iPhone이고 Health Connect 내보내기의 원본은 Android이며, Mac 동기화를 활성화하면 Mac 앱이 로컬 대상이 될 수 있습니다. 이 데이터는:

  • 명시적으로 내보내지 않는 한 Apple HealthKit 데이터베이스 또는 Android Health Connect에 남습니다
  • 요청한 내보내기를 위해 기기에서 처리됩니다
  • 파일, iCloud Drive, Android 문서 제공자, 타사 파일 제공자, Obsidian 보관함, 페어링된 Mac이나 CLI 또는 사용자가 구성한 API 엔드포인트 등 선택한 대상으로만 내보내집니다
  • Health.md 건강 데이터베이스에 업로드되거나 추후 조회를 위해 Health.md에 보관되지 않습니다

Android Health Connect 의료 기록

Health.md는 읽기 전용 건강 데이터 이동성 및 개인 기록 관리 앱입니다. 지원되는 Android 기기에서 사용자가 직접 승인한 의료 리소스를 의료 기록(FHIR) 내보내기 기능으로 읽을 수 있습니다. Health Connect가 개인 의료 기록을 다음 범주로 구분하므로 각 범주에 별도 읽기 권한을 요청합니다:

  • 백신: 예방 접종 이력
  • 알레르기 및 불내증: AllergyIntolerance 기록
  • 질환: 진단 및 문제 목록 이력
  • 검사 결과: 검사 Observation 기록
  • 약물: Medication, MedicationRequest 및 MedicationStatement 기록
  • 개인 정보: 사용자의 기록을 식별하고 인구통계학적 맥락을 제공하는 Patient 기록
  • 의료인 정보: 진료 기록에서 참조하는 Practitioner 및 PractitionerRole 기록
  • 임신: 임신 관련 의료 기록
  • 시술: Procedure 이력
  • 사회력: 원본 시스템이 기록한 생활 방식 및 임상 맥락 관찰
  • 방문: Encounter 및 진료 방문 이력
  • 활력 징후: 의료 기록에 저장된 임상 활력 징후 관찰

이 권한은 사용자가 시작하거나 예약한 내보내기에 승인된 범주를 포함하는 데만 사용됩니다. JSON 및 제공자 기본 형식은 Health Connect가 제공한 FHIR 리소스 데이터와 원본 메타데이터를 보존하며 Markdown과 CSV 요약은 범주별 의료 리소스 수를 표시합니다. Health.md는 진단하거나 치료를 권고하거나 Health Connect에 쓰지 않으며, 건강 데이터를 광고, 프로파일링, 신용, 보험 또는 고용 결정에 사용하지 않습니다.

모든 범주는 선택 사항이며 언제든 거부하거나 철회할 수 있습니다. 다른 승인된 내보내기는 계속 작동합니다. 서버 사본은 보관하지 않으며 내보낸 기록은 사용자가 해당 대상의 제어 기능으로 삭제할 때까지 선택한 대상에 남습니다.

데이터 저장

Health.md는 Apple Health, Health Connect 또는 기타 건강 데이터를 Health.md 서버에 저장하지 않습니다:

  • 원본 데이터: Apple Health 데이터는 HealthKit에, Android 건강 데이터는 Health Connect에 남습니다
  • 내보낸 데이터: Markdown, Obsidian, CSV 및 JSON 파일은 선택한 대상에 기록됩니다
  • 직접 전송: 페어링된 Mac과 CLI는 모바일 원본에서 직접 데이터를 받고 자체 로컬 작업 상태를 유지합니다
  • 파일 제공자 동기화: iCloud Drive, Dropbox, Google Drive, Working Copy, Syncthing, OneDrive 등은 자체 약관에 따라 저장·동기화합니다
  • API 엔드포인트: 구성된 경우 선택한 내보내기가 직접 전송되며 해당 서비스의 보안·로그·보관·삭제 정책을 따릅니다
  • 앱 환경설정: 일정, 폴더, 템플릿, 연결 및 잠금 해제 설정은 플랫폼 저장소, StoreKit 또는 Google Play Billing에 저장됩니다

당사는 원본 건강 데이터베이스, 로컬 내보내기 파일 또는 사용자가 제어하는 대상에 접근할 수 없습니다. 별도의 분석 및 캠페인 기록에는 건강 데이터나 내보내기 콘텐츠가 없습니다.

타사 서비스

앱에는 광고 SDK, 타사 분석·기여도 SDK 또는 타사 추적이 없습니다. 앱은 플랫폼 서비스, 자사 인프라 및 사용자가 선택한 대상과 상호작용합니다:

  • Apple HealthKit: 명시적 권한으로 기기에서 Apple Health 데이터를 읽기 위해
  • Android Health Connect: 명시적 권한으로 기기에서 Android 건강 기록을 읽기 위해
  • 선택적 건강 제공자 API: 직접 가져오기를 명시적으로 활성화한 경우 제공자 OAuth를 사용하고 토큰을 기기에 저장할 수 있습니다
  • Apple 파일, Android Storage Access Framework 및 파일 제공자: 선택한 폴더에 파일을 쓰기 위해
  • StoreKit, App Store 및 Google Play Billing: 일회성 Full Access 구매·복원을 위해
  • Google Play Install Referrer: Android에서 유효한 캠페인 설치를 정제된 자사 메타데이터와 연결하기 위해
  • Cloudflare: 허용 목록 분석, 캠페인 리디렉션, 최소화된 D1 기록, 보관 정리, 종합 오용 제한 및 웹사이트 제공·분석을 위해
  • 로컬 네트워크/근거리 연결: Mac 동기화 시 선택적 Mac 대상을 찾고 기록하기 위해

웹사이트 분석

healthmd.app은 간단한 분석 게이트 확인 후 Cloudflare Web Analytics로 종합 트래픽, 성능 및 인기 페이지를 파악합니다. 이 사이트에서는 클라이언트 쿠키를 사용하지 않으며 건강 데이터, 내보낸 파일, 구매 상태 또는 앱 설정과 연결되지 않습니다.

Google Fonts나 jsDelivr 같은 타사 CDN에 글꼴·자산을 요청할 수 있으며, 해당 제공자는 자체 정책에 따라 IP 주소, 브라우저, 참조 페이지 및 요청 URL 같은 표준 웹 요청 정보를 받을 수 있습니다.

네트워크 활동

로컬 내보내기는 건강 데이터를 Health.md로 보내지 않습니다. 네트워크 활동은 사용자가 시작한 기능이나 플랫폼 서비스로 제한됩니다:

  • Full Access의 StoreKit, App Store 및 Google Play 구매·복원
  • Mac 대상을 활성화한 경우 로컬 네트워크 탐색·전송
  • 선택한 폴더의 iCloud Drive, Android 문서 제공자 또는 타사 파일 제공자 동기화
  • 지원되는 직접 건강 원본을 명시적으로 연결한 경우 OAuth 또는 API 요청
  • 모바일 원본이 사용 가능할 때 명시적으로 페어링된 CLI 또는 MCP 클라이언트의 실시간 직접 쿼리
  • 명시적으로 구성한 HTTPS API 엔드포인트로 사용자가 요청한 내보내기 전송
  • App Store 또는 Google Play의 앱 업데이트
  • 앞서 설명한 허용 목록 기반 자사 제품 분석
  • 앞서 설명한 자사 캠페인 리디렉션 및 Android 설치 기여도
  • 브라우저로 healthmd.app 방문 시 웹사이트 분석 및 CDN 요청

권한

Health.md는 다음 플랫폼 권한을 요청할 수 있습니다:

  • 건강 데이터(HealthKit): 사용자가 선택한 범주를 읽습니다. iOS 설정 → 건강 → 데이터 접근 및 기기 → Health.md에서 변경할 수 있습니다.
  • Health Connect 피트니스 및 웰니스 데이터: 승인한 특정 Android 범주를 읽습니다.
  • Health Connect 의료 기록: 위 FHIR 내보내기의 각 의료 범주를 별도로 읽습니다.
  • 파일 시스템 접근: Apple 파일 선택기 또는 Android Storage Access Framework로 선택한 위치에 파일을 씁니다.
  • 로컬 네트워크: Mac 동기화 시 Mac 컴패니언을 찾고 작업을 보냅니다.
  • 알림: 예약 내보내기에 수동 조치가 필요하거나 완료되었을 때 알립니다.

권한은 명시된 목적으로만 사용되며 플랫폼 설정에서 언제든 철회할 수 있습니다.

아동의 개인정보

Health.md는 광고나 아동 대상 프로파일링을 위해 이름, 연락처, 건강 데이터 또는 계정 프로필을 요구하지 않습니다. 웹사이트 및 캠페인 측정은 종합 성과 측정을 위한 것이며 아동 대상 광고·프로파일링을 위한 것이 아닙니다.

데이터 보안

Health.md는 각 저장 경로에 적합한 기술적·조직적 보호 조치를 사용합니다:

  • 건강 데이터는 Apple·Android 기기 보안과 HealthKit·Health Connect 권한으로 보호됩니다
  • 내보낸 파일은 저장한 파일 시스템, 보관함, 클라우드 드라이브, 문서 제공자 또는 Mac 폴더로 보호됩니다
  • 보호되는 API 엔드포인트 내보내기 모드에는 HTTPS가 필요하며 대상 서비스가 저장·보관을 제어합니다
  • 직접 Mac·CLI 전송은 인증·암호화 채널, 제한된 프레임, 무결성 검사 및 명시적 페어링을 사용합니다
  • 기기 암호 사용, 운영체제 업데이트 및 동기화 제공자 권한 검토를 권장합니다
