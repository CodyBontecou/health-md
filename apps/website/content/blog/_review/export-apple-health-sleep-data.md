Verified: 2026-10-25

Scope: website guidance, existing exported examples, and source/documentation tracing. No simulator, device, UI automation, new capture, or real health export was run for this article. ## Claims

- [x] Manual iPhone folder export needs authorized Apple Health data and a writable Files destination, not a Mac. Preview precedes Export Data; users inspect written/skipped/failed results and the destination. Evidence: `docs-src/src/content/docs/iphone-first-export.md`, `folder-vault.md`, and `apps/apple/HealthMd/Shared/Managers/VaultManager.swift`. No claim that preview proves a file write succeeded.
- [x] Sleep metrics and labels include Total Sleep, Bedtime, Wake Time, Deep Sleep, REM Sleep, and Core Sleep. Evidence: `apps/apple/HealthMd/Shared/Models/HealthMetrics.swift` sleep definitions; `docs-src/src/content/docs/metrics.md`. Availability is qualified by permissions, source, OS and app version. Inspected image: `docs-src/public/assets/docs/iphone-first-export/metric-selection.webp`; its Sleep row is off, exactly as captioned.
- [x] Summary, Detailed Time-Series, and Lossless Health Records have distinct purposes; the latter is Apple-only. Evidence: `docs-src/src/content/docs/format.md`, section Data Detail and profiles, and the generated format/canonical-record references. The article does not promise a complete archive or every stage on every device.
- [x] Sleep belongs to its local start date; late synchronization can require re-exporting that day. Evidence: `docs-src/src/content/docs/sleep-date-attribution.md` and `content/blog/why-sleep-is-in-yesterdays-note.md`. Monday-to-Tuesday example deliberately matches that reference. Canonical start/end details are not reconstructed from a daily total.
- [x] The CSV names, seconds units, compatibility summary widths and timestamped Sleep Stage row match the producer. Evidence: `apps/apple/HealthMd/Shared/Export/CSVExporter.swift` Sleep block and `apps/apple/docs/reference/generated/core/summary-day.csv`, published byte-identically at `docs-src/public/reference/generated/core/summary-day.csv`. The new excerpt preserves original rows and their source order; it is explicitly fictional, partial and not a complete night. `27,900 / 3,600 = 7.75` hours.
- [x] Value is mixed-type; filter Category/Metric/Unit before numeric analysis, and preserve CSV quoting. Evidence: the reusable CSV header entry in `verified-snippets.md` and the same producer fixture. The selected stage value is text with a duration; its row is not an extra nightly total. A focused publication test checks the new excerpt against both producer and published fixture and the article's inline copy.
- [x] In-bed and detailed stage samples can overlap; Apple also has asleepUnspecified. Evidence: Apple's `HKCategoryValueSleepAnalysis` documentation, checked 2026-10-25: https://developer.apple.com/documentation/healthkit/hkcategoryvaluesleepanalysis. The article explains data representation without offering sleep-quality or medical interpretation.
- [x] Existing source data, selected date, authorization, metrics, synchronization, units and destination can explain empty/different results. Empty output does not establish a zero or a specific permission state. Evidence: `docs-src/src/content/docs/troubleshooting.md`, `iphone-first-export.md`, `sleep-date-attribution.md`, and `reference/query-manifests-and-diagnostics.md`. The article does not claim HealthKit reveals all read-denial states.
- [x] App read/write permissions can be reviewed in Apple Health; Apple's native Export All Health Data is XML. Evidence: https://support.apple.com/guide/iphone/share-your-health-data-iph5ede58c3d/ios, checked 2026-10-25. The article links the existing broad export guide rather than claiming Health.md converts an XML archive.
- [x] Five free export actions and a lifetime unlock match the current iPhone product explanation. Evidence: `docs-src/src/content/docs/paywall.md` and `apple-health-to-csv/index.html`. Exact localized purchase price is not asserted. App Store URL is the registry's verified URL.
- [x] Schedules are OS-controlled targets and depend on source synchronization/protected-data access. Evidence: `docs-src/src/content/docs/scheduling.md` and `apps/apple/docs/features/scheduled-exports.md`. No exact execution guarantee or newly tested schedule is claimed.
- [x] Android shares the start-day convention but stage identities, source statistics and profiles must not be silently equated. Evidence: `docs/architecture/cross-platform-unification-policy.md`, `docs-src/src/content/docs/sleep-date-attribution.md`, and `health-connect-export/index.html`. No mobile implementation or export contract changed.

The optional single-owner pilot retains intentionally uploaded API exports, with no public signup or automatic sync. Evidence: `privacy-policy.html`, current `apple-health-export/index.html`, and reusable privacy/provider entries in `verified-snippets.md`. The public privacy checker covers the new article's built HTML in addition to general prohibited-claim scanning.
