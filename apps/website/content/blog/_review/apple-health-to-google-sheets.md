## Claims

- [x] **Daily CSV uses the header `Date,Category,Metric,Value,Unit,Timestamp`; `Value` is mixed-type.**
  `apps/apple/HealthMd/Shared/Export/CSVExporter.swift` writes the header and
  unconditional schema, unit-system, time-zone, and raw-capture-status rows.
  `apps/apple/docs/reference/generated/core/summary-day.csv` contains
  `healthmd.health_data`, `UTC`, and `not_requested` in `Value`, as well as
  clock times, booleans, and UUIDs. `lossless-day.csv` adds quoted JSON archive
  rows. These are generated by production `toCSVThrowing` calls in
  `apps/apple/HealthMdTests/Documentation/GeneratedExportDocumentation.swift`,
  not examples invented for this article. Registry: `verified-snippets.md` →
  "CSV export header contract".
- [x] **Consumers accept five-field summary rows and six-field rows, including empty timestamps.**
  Traced to `apps/apple/docs/reference/generated/core/csv-row-contracts.md`
  and the summary/lossless CSV fixtures. Daily Steps and Total Duration rows
  have five fields; metadata rows have six with an empty Timestamp;
  timestamped sample rows have six with a populated ISO-8601 timestamp.
- [x] **The numeric step filter is Activity / Steps / count; the sleep-duration filter is Sleep / Total Duration / seconds.**
  These exact Category, Metric, and Unit values appear in `summary-day.csv`
  and are written by the Activity and Sleep branches of `CSVExporter.swift`.
  Sleep Stage rows can contain text even though their Unit is seconds, so
  selecting only a broad sleep category is insufficient.
- [x] **All daily rows must reach one raw-data table, with one header, before creating the weekly pivot.**
  Each generated daily CSV fixture contains one Date. Google's
  [pivot-table documentation](https://support.google.com/docs/answer/1272900?hl=en)
  says to select the source cells, requires column headers, and exposes an
  explicit source range. Separate imported tabs do not extend that range.
  Step 2 appends data rows without repeated headers and checks all dates;
  Step 3 selects the complete filtered analysis table. When more days are
  appended, the instructions refresh the analysis copy and expand the range.
  `test/blog-export-workflows.test.mjs` checks this ordering in the article.
- [x] **Coerce only the selected numeric metric; failed conversion and missing values must not become zero.**
  Google's [VALUE documentation](https://support.google.com/docs/answer/3094220?hl=en)
  describes conversion of recognized number, date, or time strings and an
  error for unconvertible text. The article filters first, uses `=VALUE(D2)`
  on the analysis copy, and checks errors/blanks. Number formatting alone
  does not make schema/status/JSON rows numeric measurements.
- [x] **`=DATEVALUE(A2)` converts a text date; `=A2-WEEKDAY(A2,2)+1` labels its Monday-starting week.**
  Google's [DATEVALUE documentation](https://support.google.com/docs/answer/3093039?hl=en)
  requires a string and returns a date serial number; the article applies it
  only to text dates and pastes values back before formatting as Date.
  Google's [WEEKDAY documentation](https://support.google.com/docs/answer/3092985?hl=en)
  states that type 2 numbers Monday as 1 and Sunday as 7. Subtracting that
  number and adding 1 gives the week's Monday. The pivot averages selected
  daily totals for recorded dates, or sums them if the user chooses SUM;
  missing days are not fabricated as zero. Formulas were traced, not entered
  into a live spreadsheet.
- [x] **Local CSV combination must preserve quoted fields and only one header.**
  `CSVExporter.swift` uses CSV field escaping and a quoted JSON-field sink.
  The downstream-parser guidance in `apps/apple/docs/features/export-schema.md`
  explicitly allows commas, quotes, and newlines in RFC 4180 fields.
  `lossless-day.csv` demonstrates quoted JSON cells.
- [~] **Sheets UI labels and the import/copy/chart workflow.**
  File > Import > Upload, "Replace spreadsheet", "Insert new sheet(s)", and
  Insert > Chart retain the earlier 2026-09-26 spot-check evidence.
  Data > Create a filter and Insert > Pivot table are traced to Google's
  [filter documentation](https://support.google.com/docs/answer/3540681?hl=en)
  and pivot-table documentation above. No authenticated Sheets import,
  append, filtered copy, formula entry, pivot, or chart was executed during
  this correction. A full synthetic-file click-through remains recommended.
