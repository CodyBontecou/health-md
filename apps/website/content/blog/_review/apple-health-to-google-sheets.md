## Claims

- [x] Apple native Export All Health Data produces XML; this tutorial instead reads authorized HealthKit data and exports CSV. It neither converts a saved XML archive nor establishes a live Sheets connection. Evidence: `apple-health-export/index.html`, Apple https://support.apple.com/guide/iphone/share-your-health-data-iph5ede58c3d/ios, and `apps/apple/HealthMd/Shared/Export/CSVExporter.swift`. Scope is Apple; no cross-platform contract changes.
- [x] iPhone authorization, writable Files folder, selected date, metrics, preview, CSV, Summary, and YYYY-MM-DD format match `docs-src/src/content/docs/iphone-first-export.md` and `format.md`. A manual export needs no Mac; this tutorial separately uses the computer browser version of Sheets. Five free actions/lifetime unlock: `paywall.md`. App Store URL: `verified-snippets.md` registry.
- [x] CSV uses one daily file and `Date,Category,Metric,Value,Unit,Timestamp`. Value is mixed-type, not one numeric column; summary rows may omit Timestamp, while quoted JSON can contain commas/newlines. Evidence: `apps/apple/HealthMd/Shared/Export/CSVExporter.swift`, `apps/apple/docs/reference/generated/core/summary-day.csv`, `lossless-day.csv`, and `csv-row-contracts.md`; published fixture at `docs-src/public/reference/generated/core/summary-day.csv`. Registry entry: CSV export header contract. Daily totals must remain distinct from detailed samples and weekly/monthly rollups.
- [x] Exact filters and examples come from the producer fixture: Activity / Steps / count = 12500 on 2026-03-15; Sleep / Total Duration / seconds = 27900.0. The latter equals 7.75 hours; the former's Monday is 2026-03-09. These are fictional sample measurements, not new collected health data. Start-day sleep attribution: `docs-src/src/content/docs/sleep-date-attribution.md` and published sleep guide.
- [x] Computer File > Import, import locations (including Replace spreadsheet and Insert new sheets), comma separator, and Upload are documented by Google, checked 2026-10-25: https://support.google.com/docs/answer/40608?hl=en and https://support.google.com/docs/answer/12236443?hl=en. The article restricts replacement to an empty workbook, appends every daily file into one raw-data table without repeated headers, and checks dates. Separate temporary tabs do not automatically extend a pivot's source range. Original CSVs are retained because Sheets may recognize dates and numbers during import.
- [x] File > Settings controls whole-spreadsheet locale and function language: https://support.google.com/docs/answer/58515?hl=en. The tutorial explicitly sets United States before import to match decimal-point numeric text, uses English function syntax, and requires inspecting imported cells. No unverified auto-conversion checkbox label is required.
- [x] Data > Create a filter and filter-by-values behavior: https://support.google.com/docs/answer/3540681?hl=en. The analysis copies only the rows matching all three identifiers and checks copied rows and duplicate dates before aggregation. Overlapping re-exports must be resolved, not summed. No claim of automatic deduplication or complete seven-day coverage.
- [x] VALUE parses recognized numeric/date/time strings and errors on invalid text: https://support.google.com/docs/answer/3094220?hl=en. It is used only after numeric metric selection, with an IF blank guard. DATE receives explicit numeric components from YYYY-MM-DD text: https://support.google.com/docs/answer/3092969?hl=en. The conversion is applied only to text dates then pasted as values into column A; existing date values are preserved. WEEKDAY type 2 is Monday=1: https://support.google.com/docs/answer/3092985?hl=en, so `=A2-WEEKDAY(A2,2)+1` returns Monday. Formulas are traced, not executed in Sheets; invalid/missing data is never replaced with zero.
- [x] Insert > Pivot table requires column headers and explicit source range; fields can be placed in Rows/Values and their summaries adjusted. Pivots update when source cells change: https://support.google.com/docs/answer/1272900?hl=en and https://support.google.com/docs/answer/7572895?hl=en. The guide explicitly expands ranges and rebuilds manual analysis copies after appending data. AVERAGE is over recorded numeric dates only; SUM means recorded weekly total.
- [x] Values-only paste is documented by https://support.google.com/docs/answer/12236443?hl=en. Chart insertion, source selection and chart type: https://support.google.com/docs/answer/63824?hl=en. Chart data uses a separate manual copy sorted by date, with refresh/range limits explained. No automatic phone-to-Sheets synchronization or scheduled upload is promised.
- [x] Troubleshooting is consistent with `docs-src/src/content/docs/troubleshooting.md`, the CSV landing page and producer row shapes. An absent row does not establish zero or expose a read-denial state. The guide offers spreadsheet handling, not medical interpretation.
- [x] Local folder export has no Health.md server copy by default; Google stores uploaded files under its terms and sync providers govern their copies. The separate opt-in single-owner Cloud pilot retains only API exports intentionally uploaded, has no public signup or automatic device sync, and is not generally available. Evidence: `privacy-policy.html`, current export hub, `verified-snippets.md` core/provider entries, and `test/blog-workflow-privacy.test.mjs`. The public privacy checker explicitly includes this published slug and its sitemap revision.
- [x] Existing blog generator provides canonical, social and BlogPosting metadata, index and sitemap publication. CSV, export hub and blog directory link to the existing Sheets slug; Excel and sleep guides are linked from the article. The Claude and local-export drafts remain unpublished. Evidence: `scripts/build-blog.mjs`, `test/blog-verification.test.mjs`, `test/blog-draft-exclusion.test.mjs`, and full built-site checks. This ledger is excluded from public output.
