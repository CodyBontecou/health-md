## Claims

### 2026-11-19 refresh

- [x] Opening answer: WHOOP "How to Export Your Data" (https://support.whoop.com/s/article/How-to-Export-Your-Data?language=en_US, dated Nov 17, 2025, read 2026-11-19) says iOS: More icon → App Settings → Data Export; Android: More icon → Data Export; confirm email; select Create Export; email with download link within 24 hours; export links expire after 7 days. FAQ: "Most requests are processed within 24 hours", check spam or contact WHOOP Member Support; data exported in CSV format, opens in Excel, Google Sheets or any spreadsheet tool. No install CTA precedes these steps.
- [x] File table: same article, "Standard Data Exports (All Members)" table, four rows (Physiological Cycles, Sleeps, Workouts, Journal Entries) with the data-included lists restated in the guide; SpO2 and skin temperature marked WHOOP 4.0+. "WHOOP One, Peak, and Life members all receive standard data exports, while WHOOP Life members with WHOOP MG receive additional health data." MG data named as ECG, IHRN and Blood Pressure Insights in the article's regulatory section. Lowercase file names (physiological_cycles.csv etc.) are attributed to user posts only (community thread 16226 lists physiological_cycles, sleeps, workouts, journal_entries), not to WHOOP.
- [x] Steps gap: WHOOP's table lists no steps. User reports, labeled as such: https://www.community.whoop.com/t/exporting-step-count/14416 (April 2, 2026, "it does not include the step count anywhere", no replies) and https://www.community.whoop.com/t/expose-step-count-in-the-developer-api-and-the-data-export/16226 (September 13, 2026, searched all four CSVs, no steps). Developer API change: https://www.community.whoop.com/t/step-count-now-available-in-the-whoop-developer-api/16424 (posted October 6, 2026) and a September 29 post in thread 16226 say that from September 23, 2026, cycles from GET /v2/cycle and /v2/cycle/{cycleId} include step_count; step count follows the WHOOP cycle (wake to next wake); null rather than 0 when unavailable (e.g. strap not worn). The poster's staff status is not shown on the page, so the guide says "community announcement", not "WHOOP staff". Neither post mentions the CSV export; the guide says neither post claims the CSV gained steps and tells readers to check their own headers, dated 2026-11-19.
- [x] Strength detail: stated only as the absence of sets, reps or weights from WHOOP's Workouts row (activity name, duration, strain, HR zones, energy burned, GPS). No claim about what WHOOP's app tracks for strength.
- [x] HRV/Apple Health: WHOOP Apple Health Integration (https://support.whoop.com/s/article/Apple-Health-Integration?language=en_US, dated Apr 16, 2026, read 2026-11-19), FAQ "Why is my HRV missing in Apple Health?": Apple uses SDNN, WHOOP calculates RMSSD, "WHOOP does not export HRV data to Apple Health at this time." Physiological Cycles includes HRV per the export table.
- [x] Apple Health sharing: same article. Connect path More → App Settings → Integrations → Apple Health → Connect → Turn on all or specific categories → Allow. "Exported from WHOOP to Apple Health": workouts (auto-detected), active energy, heart rate, sleep tracking, RHR, respiratory rate, blood oxygen, steps (if enabled in WHOOP settings). WHOOP MG does not export ECG nor Blood Pressure Insights. Imported list (workouts, routes, active energy, distance, mindful minutes, weight and height, heart rate) supports "a type WHOOP reads is not necessarily one it writes". Duplicate-workout FAQ supports the duplicates sentence.
- [x] Health Connect sharing: WHOOP Health Connect Integration For Android (https://support.whoop.com/s/article/Google-Health-Integration-For-Android?language=en_US, dated Oct 6, 2025, read 2026-11-19). Path: More tab → Account & Settings → Integrations → Health Connect → Set Up, grant categories. Exported: exercise, calories, steps, sleep, RHR, respiratory rate, SpO2. Not synced: Heart Screener, Blood Pressure Insights, WHOOP Age, Pace of Aging, VO2 Max. Membership Requirements section: some categories require specific memberships. Imported list includes distance, weight, height, body fat, lean body mass.
- [x] Health.md workflow: unchanged from the 2026-10-30 pass (read access, Health Connect source on Android, folder, metrics, date, CSV/JSON/Markdown, preview, one file per day). Health.md does not import WHOOP's CSV (stated). No WHOOP score reconstruction. Calendar-day framing follows the steps guide (HealthKit cumulative-sum query for the selected day) and per-day Android exports.

The Play-flavor code (commit 52afcb073 "Restrict direct provider rollout to WHOOP") is an ancestor of tag android/v3.5.2, but no tag message, release note or production-track record in the repository confirms that build reached the public Google Play production track (tags say Internal Testing for 3.5.0; apps/android/release-scope.json lists 3.5.6 as a release candidate on the internal track). Per the brief, not mentioned. No iPhone direct WHOOP connection is mentioned.
