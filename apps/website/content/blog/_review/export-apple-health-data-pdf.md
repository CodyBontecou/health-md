## Claims

- [x] Clinician Report is a separate Settings workflow on iPhone and Android, not a scheduled format or Mac report feature; no vault or daily export format setup is required. Evidence: `docs-src/src/content/docs/clinician-report.md`, `apps/apple/docs/features/clinician-report.md`, `apps/android/docs/features/clinician-report.md`, and native report entry/view source. Apple path is Settings / Profiles & Reports / Clinician Report. Android is acknowledged with its own source/native controls rather than false HealthKit parity. Cross-platform policy reviewed; no capability, public contract or clinician-service behavior changed.
- [x] Report presets are 7/30/90 days and custom, include today and both boundary dates, and use a pinned device timezone during generation. Evidence: `ClinicianReportModels.swift` ReportDateRange.preset/normalized/dates; `ClinicianReportViewModel.swift` generateReport and reportCalendar. October 1–7 is seven local calendar dates; no fictional measured health values are introduced.
- [x] Eleven ReportMetric cases are bloodPressure, restingHeartRate, heartRate, weight, bloodGlucose, oxygenSaturation, respiratoryRate, bodyTemperature, sleepDuration, steps and workouts. HRV is absent. Detail levels are summary and summaryAndReadings. Evidence: `ClinicianReportModels.swift`, `ClinicianReportView.swift`, report generator and architecture spec `docs/features/clinician-report-v1.md`. The report measurement choice is independent of daily export toggles. Tables vary by metric; no complete raw archive or all-Health-data promise.
- [x] Current English iPhone resource strings are Generate Report, Summary only, Summary + individual readings, and Share or Save PDF. Evidence: `apps/apple/HealthMd/Localizable.xcstrings` clinician_report_preview/summary_only/summary_readings/share_or_save_pdf keys and `ClinicianReportCopy.swift`. `generateReport` prepares source data and automatically calls PDF generation when reportable data exists. Evidence: `ClinicianReportModels.swift` configuration comment, view model persistence helpers, `ClinicianReportPDFRenderer.swift` metadata and renderArtifact filename. - [x] Report statistics/coverage/counts/readings are measurement-specific, with inclusive expected-day denominator; steps are daily totals and workouts are session entries.
