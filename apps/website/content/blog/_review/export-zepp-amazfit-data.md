## Claims

- [x] Amazfit Stratos 3 support doc https://support.amazfit.com/it/amazfit_stratos_3/docs/CQCWdRLxEoJhw8x9UcLcsMESnsq: export an activity record from the watch as GPX (open record, swipe left, Export, connect to computer, GPX date folder; no transport such as USB is claimed). Article scopes it to older models (Stratos 3, Pace via FAQ 658; FAQ 992 index) and does not claim other watches share the menu. FAQ pages render client-side, so only the Stratos 3 doc is quoted.
- [x] Amazfit GTS 2 mini doc https://support.amazfit.com/en/amazfit_gts_2_mini/docs/N6cUdJxDRo6rbfxiLs1cJDBrnRd: Apple Health sharing/data source and Add accounts (Strava, Relive) under Profile in Zepp. Device-specific; no universal category list, history or Health Connect step claimed. Strava downloads link to the maintained Strava guide, which cites Strava's own export article (GPX needs GPS points).
- [x] No claim of a universal per-activity GPX/TCX/FIT export in the Zepp app, a Zepp archive importer, full-history backfill, or Health.md signing in to Zepp. Article says to check the watch's support page. Renaming a file extension does not convert formats (general statement, no product claim).
- [x] https://www.zepp.com/privacy-support documents Export data, Zepp Profile/Setting/Exercising user rights, and Zepp Life Profile/Setting/Account and Security. Format, contents and timing are not documented; article says so.
- [x] https://zepp.com/blog/your-data-your-storage-your-choice (Sept 2026): 10.8.5 cloud-sync controls, expanded export/restoration in future phases. Article states these are not historical export or restore.
- [x] Apple iPhone User Guide (https://support.apple.com/guide/iphone/welcome/ios) linked for managing which apps share data with Health; the profile → Apps → Zepp category toggles are Apple Health's standard sharing screen. The page only says a sleep entry does not establish that a sleep score is present, and a workout does not prove a route or heart-rate stream was shared; no claim about which Zepp fields are shared. The specific Apple Health-sharing topic URL could not be confirmed offline, so the guide root is linked.
- [x] Maintained iphone-first-export, format, workout, sleep and weight guides plus committed Apple HealthKitManager establish separate read permission, one-day first export, default Markdown, CSV/JSON, daily files. No archive importer promised; the free-action count is omitted.
- [x] Existing privacy retention and local-destination guide establish core folder versus optional Cloud pilot (separate, opt-in, single-owner, not generally available) boundaries. Strava guide gains one sentence linking here.
