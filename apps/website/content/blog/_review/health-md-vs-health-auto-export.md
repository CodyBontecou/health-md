## Claims

- [x] Health.md daily CSV/JSON/Markdown/Bases output, selectable detail, frontmatter/templates and managed Daily Note Injection are documented by `docs-src/src/content/docs/format.md`, `daily-notes.md`, `export.md`, and the production-backed `apps/apple/docs/reference/generated/core/summary-day.csv`. The CSV fixture is fictional; mixed metadata/canonical values are not numeric daily totals. Format names do not establish cross-app schema equivalence. No contract change.
- [x] Health.md profile schedules are best effort under iOS background and locked-data limits; API Endpoint sends a versioned JSON envelope directly to the configured receiver. Evidence: `docs-src/src/content/docs/scheduling.md`, `export-profiles.md`, `api-endpoint.md` and `shortcuts.md`. Full Access requirements remain qualified rather than promising all workflows in the free allowance.
- [x] Health.md has five completed export actions and lifetime options, with the localized StoreKit sheet authoritative. Evidence: `docs-src/src/content/docs/paywall.md`. Bundled Mac MCP needs the open Mac app and connected iPhone for fresh reads; portable direct MCP is explicitly an unqualified preview. Evidence: `docs-src/src/content/docs/mcp.md` and `release-status.md`. This article does not promote development-source-only capabilities or claim Android equivalence.
- [x] Health Auto Export currently lists CSV, JSON, Markdown, GPX, Shortcuts and MCP, plus Free, Basic and Premium purchasing options with a seven-day Premium trial. Sources checked 2026-10-26: https://apps.apple.com/us/app/health-auto-export-json-csv/id1115567069 and https://github.com/Lybron/health-auto-export#pricing. The publisher's landing page/README omit Markdown in some format summaries; the article specifically attributes Markdown to the current App Store listing. No claim that it lacks Markdown, AI, automation or a lifetime purchase.
- [x] Health Auto Export manual CSV aggregation and destination integrations are documented at https://help.healthyapps.dev/en/health-auto-export/manual-export/ and https://www.healthyapps.dev/apps/health-auto-export/ . Automation timing is not guaranteed: https://help.healthyapps.dev/en/health-auto-export/faq/ . Its current MCP server guide documents foreground iPhone, local network clients, HTTP bearer authentication and optional HTTPS: https://help.healthyapps.dev/en/health-auto-export/automations/server-connection/ . Older FAQ TCP security wording is not generalized to its current HTTP transport. No hands-on Obsidian compatibility claim.
- [x] Health.md folder exports do not create a Health.md server copy; the separate optional Cloud pilot has its own retention policy. Evidence: `privacy-policy.html#retention` and the existing Obsidian guide. Health Auto Export's policy describes on-device processing and direct exports to user-selected destinations: https://www.healthyapps.dev/health-auto-export/privacy-policy/ . This comparison does not claim exclusive privacy or that either app's user-selected providers have no retention.
- [x] Health.md reads authorized HealthKit data rather than importing native XML archives. Evidence: `apple-health-export/index.html`, existing CSV article and export docs. Android remains separately linked to its own guide. No unsupported competitor import limitation is asserted.
