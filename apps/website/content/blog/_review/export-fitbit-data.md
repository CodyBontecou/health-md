## Claims

### 2026-11-18 refresh

- [x] Title, description, lead and quick answer: three routes (Takeout archive, in-app TCX, Health Connect daily files) restate the sourced sections below. Quick answer says Health Connect covers new days going forward, not full history, which matches the history claim below.
- [x] "What changed on October 30, 2026": https://support.google.com/googlehealth/answer/14236613?hl=en, read 2026-11-18, says Fitbit Web APIs are no longer supported starting October 30, 2026; third-party apps are updating to work with Google Health; Google Health Support cannot restore broken connections, the developer must enable reconnection; Connections > Partner apps shows affected apps; Health Connect and Apple Health users are not affected; data already synced to the Google Health account is kept. The notice does not mention Takeout. The guide says only that the export help still documents Takeout and TCX and that the notice does not say they change, rather than claiming Google promised they are unaffected. No specific third-party project is named. No official Fitbit developer deprecation page was cited because none was confirmed; the Google Health notice is the primary source.
- [x] Takeout steps: Google Account users follow Google's download tool with Google Health selected (https://support.google.com/googlehealth/answer/14236615?hl=en, read 2026-11-18). Delivery by email link or Drive/Dropbox/OneDrive/Box, ZIP or TGZ, ZIP opens on almost any computer, a few minutes to a few days, oversized archives split into several files, and archive_browser.html describing file formats all follow https://support.google.com/accounts/answer/3024190?hl=en, read 2026-11-18.
- [x] Original Fitbit login route: Fitbit settings page Data Export, full archive request, and "Export a selection of your Fitbit data" with time period, data types and file format follow the export help, read 2026-11-18. The page names no file formats for that form, and the guide says so. This was the only in-app/selected-data export Google's help confirms; no Google Health app "Your data" menu export is documented there, so none is described.
- [x] Takeout contents are hedged, not tabulated: Google's export help names activity, exercise, sleep and heart rate as example data but publishes no folder layout or CSV/JSON split for Google Health. A candidate Google page on Fitbit data collection (support.google.com/product-documentation/answer/14811751) was fetched in en, en-SG and en-GB and contained no Takeout/CSV/JSON wording, so it is not cited. The Data Portability API Fitbit schema lists only device events, as JSON, and is not cited as a Takeout layout. The guide tells readers to use archive_browser.html and does not say which files are CSV.
- [x] Opening CSV files: Excel Data → From Text/CSV and Google Sheets File → Import are standard menu names; guidance is conditional on CSV files being present. Links to /blog/apple-health-to-excel/ and /blog/apple-health-to-google-sheets/ are framed as general spreadsheet tips, not Apple-specific steps.
- [x] TCX: Google Health app Fitness → activity → More → Export, GPS exercises as Training Center XML, share or save, from the export help read 2026-11-18. GPX is not offered on that page; the guide points to the destination's importer and makes no conversion promise.
- [x] Garmin/migration: Takeout is described as a backup, not a migration format; no product is claimed to import it. Garmin's Health Connect connection is one-way (Garmin writes, does not read back) per the maintained /blog/export-garmin-connect-data/ guide and its ledger, citing Garmin's support page. No Fitbit history transfer or backfill into Garmin is promised. FAQ answer says "not as a full history transfer".
- [x] Health.md boundaries: no Takeout import, no Fitbit or Google Health API call, no account migration, no backfill of never-shared records. Android ExportFormat enum (apps/android/app/src/main/java/com/healthmd/domain/model/ExportFormat.kt) has MARKDOWN, OBSIDIAN_BASES, JSON and CSV. Scheduling exists on Android (link to /docs/android/#scheduling-and-automation, already linked from /health-connect-export/); no price, entitlement or schedule reliability claim added.
- [x] Health Connect setup re-read 2026-11-18 at https://support.google.com/googlehealth/answer/14506680: Android 9+, adult Google Account, Fitbit accounts may need moving to a Google Account, Connections → Partner apps → Add connections → Sync your favorite health apps → Set up, medical records optional. Steps unchanged from the 2026-10-30 pass apart from the added account note.
- [x] History limit re-read 2026-11-18 at https://developer.android.com/health-and-fitness/health-connect/read-data#read-older-data: default reads up to 30 days before any permission was first granted; older reads need PERMISSION_READ_HEALTH_DATA_HISTORY. The guide keeps "normally" and "conditional" wording and sends full-history needs to Takeout.
