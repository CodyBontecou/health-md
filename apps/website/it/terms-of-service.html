4. Funzionalità dell'App

Health.md è progettata per:

  • Leggere i tuoi dati Apple Health usando le API HealthKit o i dati sanitari Android usando le API Health Connect
  • Esportare quei dati in file Markdown, Obsidian, CSV e JSON nelle destinazioni che scegli
  • Automatizzare questo processo di esportazione secondo una pianificazione che definisci, soggetta ai limiti di esecuzione in background di Apple o al comportamento di Android WorkManager
  • Inviare processi di esportazione direttamente a un Mac o una CLI facoltativi e abbinati nei flussi supportati
  • Inviare esportazioni selezionate direttamente a un endpoint API configurato dall'utente

Il trattamento principale dei dati sanitari avviene localmente sui tuoi dispositivi. Health.md non raccoglie né conserva dati sanitari sui server di Health.md. Alcuni flussi usano connessioni di rete sotto il tuo controllo o servizi di piattaforma, inclusi acquisto/ripristino App Store o Google Play, aggiornamenti dell'app, iCloud, sincronizzazione tramite fornitore di documenti Android o fornitore di file di terze parti, trasferimento a dispositivi abbinati e un endpoint API configurato dall'utente.
