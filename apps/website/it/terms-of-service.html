5. Cosa fa Health.md

A seconda della piattaforma e della disponibilità, Health.md può:

  • leggere i dati autorizzati di Apple HealthKit, WorkoutKit, Android Health Connect e delle cartelle cliniche Health Connect;
  • esportare i dati selezionati in Markdown, Obsidian, CSV, JSON, FHIR/formati nativi del fornitore e altri formati documentati;
  • scrivere in una cartella locale o sincronizzata sul cloud, in un vault o presso un fornitore di documenti, un Mac o una CLI abbinati oppure un endpoint API configurato dall'utente;
  • eseguire flussi di esportazione manuali, pianificati, tramite Shortcut o automazione Android, diretti e ripristinabili, nel rispetto dei limiti della piattaforma;
  • rispondere a query strutturate e circoscritte e restituire valori oggettivi, provenienza, copertura, dati mancanti, dati di supporto o grafici tramite client CLI e MCP supportati;
  • collegarsi a fornitori di servizi sanitari supportati previa autorizzazione e trasmettere i relativi dati al dispositivo;
  • usare infrastrutture limitate e prive di dati sanitari per pianificazione, acquisti, analisi del prodotto, attribuzione delle campagne, autorizzazione dei fornitori, fornitura del sito web e assistenza, come descritto nell'Informativa sulla privacy.

Non raccogliamo né conserviamo i tuoi dati sanitari sui server di Health.md. I dati sanitari possono comunque lasciare il dispositivo quando scegli una cartella sincronizzata, un client abbinato, un fornitore, un agente o servizio di modelli, un endpoint API o un'altra destinazione.
