CLI Setup

The Health.md CLI is a small Terminal client for the running Mac app. It lets you check readiness, start iPhone-sourced exports, and request raw filtered Health data JSON for scripts or coding agents.

The CLI does not read Apple Health directly.

HealthKit access stays on iPhone. The command talks to the local Mac app, the Mac app talks to the open iPhone app, and the iPhone reads HealthKit.

How it works

Section titled “How it works”
TerminalRuns healthmd commands. Mac appListens on localhost and owns folder access. iPhone appReads HealthKit and applies export settings. DestinationMac folder receives Markdown, Bases, JSON, or CSV files.

Requirements

Section titled “Requirements”
  • Health.md for Mac installed and open.
  • Health.md for iPhone installed, unlocked, open, and connected to the Mac app for export commands.
  • A selected writable Mac destination folder for file-writing exports.
  • No destination folder required when using --raw to return JSON without writing files.

Check readiness

Section titled “Check readiness”

Run status before triggering an export:

The response is JSON. Key fields to check:

mac_app

Should be running. If not, open Health.md on Mac.

iphone.connected

Should be true for exports. If false, unlock iPhone, open Health.md, and wait for the Mac connection.

iphone.can_trigger_exports

Should be true for file-writing exports.

iphone.can_trigger_raw_exports

Should be true for --raw JSON exports.

destination.selected / destination.writable

Both should be true when writing files to the Mac.

active_export

Should be null before starting another export.

Export from Terminal

Section titled “Export from Terminal”

By default, CLI exports use your iPhone’s saved formats, metrics, templates, filenames, and write behavior, but skip weekly, monthly, and yearly roll-up summaries for that one request. Add --use-iphone-settings when you want the saved iPhone settings exactly.

Date ranges are capped at 366 days.

Agent skill setup

Section titled “Agent skill setup”

The Mac app also includes a user-facing Health.md CLI agent skill. In the Mac app’s CLI tab, use Install Agent Skill to copy the skill into your agent’s skills directory, or copy the manual command and set SKILLS_DIR to the folder your agent reads.

The skill teaches an agent how to install healthmd, run bounded commands, interpret readiness JSON, avoid leaking raw health data, and explain next steps instead of blindly retrying failed exports.

Troubleshooting

Section titled “Troubleshooting”
JSON/errorWhat it usually meansNext action
mac_app_unreachableThe Mac app is not running or the localhost server is unreachable.Open Health.md on Mac and run healthmd status again.
iphone_not_connectedThe iPhone app is not connected to the Mac app.Unlock iPhone, open Health.md, and wait for Mac Destination connection.
unsupported_iphoneThe iPhone app version does not support CLI-triggered exports.Update Health.md on iPhone.
mac_destination_unavailableNo selected or writable Mac folder for file exports.Reselect the Mac destination folder, or use --raw if you only need JSON.
export_limit_reachedThe free export quota is exhausted.Unlock Full Access on iPhone.
healthKitNotAuthorized / healthKitFetchFailedHealth permission, iPhone lock-state, or HealthKit fetch issue.Unlock iPhone and verify Health permissions.
timed_outThe export took longer than the wait window.Check status and Mac app history before retrying; use a longer timeout for large ranges.
Privacy note.

Raw mode can return health samples directly in Terminal. Do not paste raw output into chats, logs, or bug reports unless you intentionally want to share that data.
