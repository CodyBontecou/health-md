Every feature in health.md

A complete reference for the iOS and macOS apps. Each feature is documented with annotated screenshots, every option spelled out, and the quirks of the underlying iOS / HealthKit platform called out where they bite.

How this docs is structured.

Every page shows the live screen captured from the iOS Simulator (iPhone 16 Pro, current build), plus a highlighted variant that dims the background and focuses on the controls being discussed. Sidebar groups follow the order most users encounter features: getting started → daily use → customization → integrations.

Getting Started

Step 1Onboarding — the 5-step welcome flow that connects HealthKit, picks a vault, and unlocks the app. Step 2Folder & Vault — pick where your Markdown files live, and name the subfolder. Step 3Run your first export — manual, on-demand, with a date range.

Core Features

Daily useExport — manual exports, date ranges, vault status. Set & forgetScheduling — daily/weekly background exports. Cross-deviceMac Sync — local network transfer to the macOS app.

Customization

WhatHealth Metrics — pick from 100+ metrics across 17 categories. HowFormat — Markdown / Bases / JSON / CSV, units, dates, frontmatter. GranularIndividual Tracking — one file per timestamped entry. ObsidianDaily Note Injection — merge metrics into existing daily notes.

Integrations & Account

AutomateShortcuts — 8 App Intents for date-range exports, summaries, and status. DesktopmacOS app — sync, export, schedule, history, and menu bar. PricingUnlock & Paywall — what's free, what's unlocked, restore purchases.
