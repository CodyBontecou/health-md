Every feature in health.md

A complete reference for the iOS, iPadOS, and macOS apps. Feature pages explain the product screens, while the data reference documents every metric and export structure used by Markdown, JSON, CSV, and Obsidian Bases.

How this docs is structured.

Sidebar groups follow the order most users encounter Health.md: setup, daily exports, customization, integrations, and account behavior. The Data Reference page is generated from the app's Swift metric definitions so the table stays aligned with the current build.
