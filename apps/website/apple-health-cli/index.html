From Apple Health to your terminal

  1. Install the standalone CLI

    On macOS or Linux with Homebrew, install the public preview. For Windows and other options, see the installation guide.

    brew install CodyBontecou/tap/healthmd

  2. Pair your iPhone once

    Keep Health.md open. In Sync → CLI → Direct CLI Access, scan the terminal’s pairing QR. See pairing requirements.

    healthmd direct pair --transport manual-ip

  3. Copy, run, inspect

    Run healthmd status to check readiness, then paste your command. Your iPhone reads the authorized data; the CLI saves it on your computer. Review the receipt before analysis.

Public preview. The standalone CLI’s full physical-device release qualification is still pending. Use the matching mobile build described in the CLI docs. Apple Health extraction requires your iPhone to be paired, authorized, and open.

A few things to know

Apple Health CLI questions

Is the Apple Health CLI command builder free?

Yes. This browser tool is free, with no signup. It generates commands without accessing your health data. Health.md app export limits and pricing are separate.

Can this website read my Apple Health data?

No. The builder only creates command text in your browser. To read Apple Health, run the command on your computer with a paired iPhone running Health.md and the required health permissions.

Does the Apple Health CLI work on Windows or Linux?

The standalone healthmd CLI runs on macOS, Linux, and Windows. Apple Health extraction requires a paired iPhone with Health.md open. The portable CLI is a public preview; full physical-device release qualification is still pending.

Can I export Apple Health to JSON or JSONL?

Yes. The generated extract command supports JSON and JSONL. JSON includes an extraction receipt. JSONL saves a separate .receipt.json file next to the output. Check the receipt for status and missing dates before using the data.

What is the difference between summary and lossless detail?

Summary requests daily summaries for the selected metric. Lossless requests also acquire the canonical source records needed for that metric, including source timestamps and provenance when available. Neither option guarantees that every requested record exists or is authorized.

Does this tool work with the CLI bundled in Health.md for Mac?

The builder targets the standalone CLI, which connects directly to your iPhone. The Mac app bundles a separate Swift helper that uses the Mac app by default. For direct iPhone extraction with that helper, add --backend direct before extract.
