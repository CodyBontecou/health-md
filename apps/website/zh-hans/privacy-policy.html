隐私政策

最后更新时间：2026 年 8 月 2 日

翻译说明：本简体中文译文是尚未发布的审阅稿，仅供翻译审阅。英文版本为权威文本；如本译文与英文版本有任何差异，以英文版本为准。

简明版： Health.md 不会在 Health.md 服务器上收集或存储健康数据。HealthKit 和 Health Connect 数据只在您的设备上处理，并且只会发送到您选择的目标位置，包括文件夹、文件提供方、已配对设备或用户配置的 API 端点。Health.md 会自动收集有限的第一方产品分析数据，应用内不使用第三方分析、广告或归因 SDK。这些事件绝不包含健康数值、指标名称、健康日期、导出内容、路径、已连接设备名称、凭据或用户文本，也不会用于广告或跨应用跟踪。

我们的隐私承诺

您的健康数据属于您。Health.md 只会在获得平台授权后读取数据，并且不会在服务器上保留副本。本政策说明由用户发起的导出和传输、有限的第一方产品与网站分析，以及经过最小化处理的第一方营销活动归因。

数据收集

导出无需 Health.md 账户，也不会将健康数据发送到 Health.md 服务器。 具体而言：

  • 导出健康数据无需创建或注册账户
  • Health.md 服务不会收集或保留 HealthKit 样本、Health Connect 记录、导出文档、输入的查询结果或健康数据附件
  • 应用内不含第三方分析、归因、崩溃报告、广告或跟踪 SDK
  • 产品分析和营销活动归因不包含 Advertising ID、Android ID、硬件 ID、跟踪像素、健康样本、导出内容或文件/文件夹路径
  • 只会按照下文说明收集有限的第一方产品和营销活动数据

第一方营销活动归因

Health.md 使用第一方营销活动链接，例如 healthmd.app/v/yt-csv-001，无需第三方归因 SDK 即可衡量营销活动的整体效果。Cloudflare 重定向服务会记录营销活动令牌、链接 slug、营销活动平台和内容角度、粗粒度目标位置/客户端类别、可用时的来源主机名、粗粒度国家或地区代码，以及时间戳。存储的点击记录不包含 IP 地址或完整 User-Agent。

在 Android 上，Google Play Install Referrer 可以将由营销活动带来的安装与对应活动关联起来。对于有效的营销活动安装，Android 应用会发送一个事件，其中包含由应用随机生成的安装 UUID 和事件 UUID、应用版本和构建号、经过验证的营销活动令牌/source/medium/content 元数据、事件时间，以及可选的 Play 引荐点击和安装开始时间戳。随机安装 UUID 是该次安装的持久假名化标识符，并非由设备标识符或广告标识符派生。Health.md 绝不会保留或传输完整的原始 Install Referrer。

营销活动点击与归因安装只会通过经过验证的营销活动令牌关联，用于汇总报告。营销活动归因记录最多保留 13 个月。汇总的摄取速率计数器只包含一分钟时间窗口和计数，并会在 24 小时后删除。Cloudflare 会按照其自身条款处理常规网络连接信息，但 Health.md 不会把 IP 地址、完整 User-Agent、Cloudflare 请求 ID、Cookie 或指纹数据添加到安装归因记录中。

第一方产品分析

Health.md 使用第一方 Cloudflare Worker 和 D1 数据库了解粗粒度的新手引导、激活、导出、付费墙和购买流程表现，不使用第三方分析 SDK。应用会发送随机安装 UUID、随机事件 UUID、事件名称、应用版本/构建号/平台，以及仅与事件相关且列入允许列表的粗粒度字段：新手引导步骤或明确跳过设置、免费导出次数、导出目标类别、格式数量、指标数量和日期跨度区间、付费墙上下文、StoreKit 或 Google Play 产品标识符、购买/恢复结果，以及粗粒度授权或错误类别。

产品分析绝不包含 HealthKit 或 Health Connect 数值或标识符、指标名称、健康日期、药物、锻炼、导出内容、输入的查询结果、文件夹/知识库/文件名称或路径、已连接设备名称或设备名称、账户数据、凭据或令牌、用户文本、Advertising ID、Android ID、硬件标识符、原始引荐来源、完整 User-Agent 或存储的 IP 地址。摄取服务会拒绝未知的封装字段、事件、属性和属性值。随机安装 UUID 在该次应用安装期间保持不变，因此属于假名化标识符，而不是匿名标识符；它并非由设备、账户、广告或健康标识符派生。

Health.md 会自动收集这些有限的产品事件。产品分析数据不会与广告商共享，也不会用于广告、指纹识别或跨应用跟踪。Health.md 的公开客户端和 Worker 允许列表经过专门设计，使健康记录和导出内容无法出现在分析载荷中。

经过验证的产品分析记录最多保留 13 个月，之后由每日自动清理任务删除。除经过验证的事件字段外，Health.md 不会将原始 IP 地址、完整 User-Agent、请求 URL、请求标头、凭据或请求正文添加到分析记录中。Cloudflare 会按照其自身条款处理常规网络连接信息。

应用如何工作

Health.md 使用 Apple 提供的 HealthKit API 在本地读取 Apple Health 数据，并通过 Health Connect 在本地读取 Android 健康数据。iPhone 始终是 HealthKit 导出的来源，Android 始终是 Health Connect 导出的来源；启用 Mac 同步后，Mac 应用可以作为本地目标位置。这些数据：

  • 会保留在 Apple 的 HealthKit 数据库或 Android Health Connect 中，除非您明确将其导出
  • 只在您的设备上处理，用于执行您请求的导出
  • 只会导出到您选择的目标位置，例如“文件”、iCloud Drive、Android 文档提供方、第三方文件提供方、Obsidian 知识库、已配对的 Mac 或 CLI，或用户配置的 API 端点
  • 不会上传到 Health.md 健康数据数据库，也不会由 Health.md 保留以供日后查询

Android Health Connect 医疗记录

Health.md 是一款只读的健康数据可移植和个人记录管理应用。在受支持的 Android 设备上，用户可以使用其 医疗记录（FHIR） 导出功能，读取用户在 Health Connect 中明确授权的医疗资源。Health.md 会分别请求各类别的读取权限，因为 Health Connect 将可移植个人医疗记录划分为以下类别：

  • 疫苗： 免疫接种史
  • 过敏与不耐受： AllergyIntolerance 记录
  • 疾病状况： 诊断和问题列表历史
  • 实验室结果： 实验室 Observation 记录
  • 药物： Medication、MedicationRequest 和 MedicationStatement 记录
  • 个人信息： 用于识别用户记录并提供人口统计背景的 Patient 记录
  • 医疗从业者信息： 护理记录引用的 Practitioner 和 PractitionerRole 记录
  • 孕期： 与孕期相关的医疗记录
  • 医疗操作： Procedure 历史
  • 社会史： 来源系统记录的生活方式和临床背景观测值
  • 就诊： Encounter 和护理就诊历史
  • 生命体征： 病历中存储的临床生命体征观测值

这些权限仅用于在用户手动或计划执行的导出中包含已授权类别。JSON 和提供方原生导出会保留 Health Connect 提供的 FHIR 资源数据和来源元数据；Markdown 和 CSV 摘要会按类别报告医疗资源数量。Health.md 不会诊断疾病、建议治疗、向 Health Connect 写入数据，也不会将健康数据用于广告、用户画像、信贷、保险或就业决策。

每个 Health Connect 类别均可选。用户可以随时拒绝或撤销某个类别的权限，其他已授权导出不受影响。Health.md 不会在服务器上保留 Android Health Connect 数据副本。导出的记录会保留在文件夹、文档提供方、知识库、已配对设备或用户配置的 HTTPS 端点中，直到用户通过该目标位置提供的控制功能将其删除。

数据存储

Health.md 不会在 Health.md 服务器上存储 Apple Health、Health Connect 或其他健康数据：

  • 来源数据： Apple Health 数据保留在 HealthKit 中，Android 健康数据保留在 Health Connect 中
  • 导出数据： Markdown、Obsidian、CSV 和 JSON 文件会写入您选择的目标位置
  • 直接传输： 已配对的 Mac 和 CLI 工作流直接从移动端来源接收数据，并分别保留本地作业状态
  • 文件提供方同步： 如果所选文件夹由 iCloud Drive、Dropbox、Google Drive、Working Copy、Syncthing、OneDrive 或其他提供方支持，该提供方会按照其自身条款处理存储和同步
  • API 端点： 配置后，所选导出会直接发送到该端点，并遵循该端点的安全、日志记录、保留和删除控制
  • 应用偏好设置： 计划、文件夹、模板、连接和解锁设置通过平台存储、StoreKit 或 Google Play Billing 保存

我们无法访问来源健康数据库、本地导出文件或您控制的目标位置。上文单独说明的产品分析和营销活动归因记录不包含健康数据或导出内容。

第三方服务

Health.md 应用内不含广告 SDK、第三方分析/归因 SDK 或第三方跟踪。应用会与平台服务、第一方产品/营销活动基础设施，以及您选择的目标位置交互：

  • Apple HealthKit： 在获得您的明确授权后，在设备本地读取 Apple Health 数据
  • Android Health Connect： 在获得您的明确授权后，在设备本地读取 Android 健康记录
  • 可选健康数据提供方 API： 如果您明确启用直接提供方导入，应用可能会使用提供方 OAuth 流程并在设备上存储提供方令牌，以便直接请求该提供方的数据。只有在您主动连接后，Health.md 才会使用这些提供方。
  • Apple“文件”、Android Storage Access Framework 和文件提供方： 将导出文件写入您选择的文件夹
  • StoreKit、App Store 和 Google Play Billing： 购买或恢复一次性 Full Access 解锁
  • Google Play Install Referrer： 在 Android 上，将有效 Health.md 营销活动链接带来的安装与经过清理的第一方营销活动元数据关联
  • Cloudflare： 接收列入允许列表的第一方产品分析数据、运行营销活动重定向、在 D1 中存储经过最小化处理的产品/点击/安装记录、执行保留清理、实施汇总级防滥用限流，并提供网站交付和分析
  • 本地网络 / Nearby Connectivity： 启用 Mac 同步后，发现可选 Mac 目标位置并向其写入数据

网站分析

healthmd.app 网站会在执行简短的分析开关检查后使用 Cloudflare Web Analytics，用于了解网站的汇总流量、性能和热门页面。本网站不使用客户端 Cookie；网站分析也不会连接到您的 Apple Health 数据、Health Connect 数据、导出文件、StoreKit 或 Google Play 购买状态，或应用内设置。

网站页面还可能从 Google Fonts 或 jsDelivr 等第三方 CDN 请求字体或资源。这些提供方可能会按照其自身政策接收标准 Web 请求信息，例如您的 IP 地址、浏览器、来源页面和请求的 URL。

网络活动

本地导出工作流不会将健康数据发送给 Health.md。 网络活动仅限于您主动使用的功能或平台服务，例如：

  • 通过 StoreKit、App Store 和 Google Play 购买或恢复 Full Access
  • 启用 Mac 目标位置时进行本地网络发现和传输
  • 如果您为导出文件选择了相应文件夹，则通过 iCloud Drive、Android 文档提供方或第三方文件提供方同步
  • 如果您明确连接受支持的直接健康数据来源，则发起可选的提供方 OAuth 或 API 请求
  • 移动端来源可用时，由明确配对的 CLI 或 MCP 客户端发起实时直连查询；Health.md 不会在服务器上保留这些结果
  • 如果您明确配置并选择 HTTPS API 端点，则向该端点传送用户请求的导出
  • 由 App Store 或 Google Play 提供应用更新
  • 上文所述且列入允许列表的第一方新手引导、激活、导出、付费墙和购买流程分析
  • 上文所述的第一方营销活动重定向和 Android 营销活动安装归因
  • 您通过浏览器访问 healthmd.app 时产生的网站分析和 CDN 请求

权限

Health.md 可能会请求以下平台权限：

  • 健康数据（HealthKit）： 用于读取您为自主导出和直连查询选择的 Apple Health 类别。您可以在 iOS“设置”→“健康”→“数据访问与设备”→ Health.md 中授予或撤销类别权限。
  • Health Connect 健身和健康数据： 用于读取您授权用于自主导出的特定 Android 健身、健康、活动、身体、营养、生殖健康和生命体征数据类别。
  • Health Connect 医疗记录： 用于读取上文医疗记录（FHIR）导出功能中分别授权的疫苗、过敏/不耐受、疾病状况、实验室结果、药物、个人信息、医疗从业者信息、孕期、医疗操作、社会史、就诊和医疗生命体征类别。
  • 文件系统访问： 用于将导出文件写入您选择的文件系统位置。您可以通过 Apple 文件选择器或 Android Storage Access Framework 选择器选择该位置。
  • 本地网络： 启用 Mac 同步后，用于发现 Mac 配套设备并向其发送导出作业。
  • 通知： 用于在计划导出需要手动处理或已经完成时通知您。

这些权限只用于所述目的，您可以随时在 iOS、iPadOS、macOS 或 Android 设置中撤销。

儿童隐私

Health.md 不会为了广告或面向儿童的用户画像而索取姓名、联系方式、健康数据或账户资料。上文所述的网站和营销活动衡量只用于评估整体表现，不用于面向儿童的用户画像或广告。

数据安全

Health.md 会根据不同存储路径采用相应的技术和组织保障措施：

  • Apple HealthKit 数据受 Apple 设备安全机制和 HealthKit 权限保护；Android 健康数据受 Android 设备安全机制和 Health Connect 权限保护
  • 导出文件由其所在的文件系统、知识库、云端硬盘、Android 文档提供方或 Mac 文件夹提供保护
  • Health.md 的受保护 API 端点导出模式要求使用 HTTPS；目标服务自行控制存储和保留策略
  • Mac 直连和 CLI 传输使用经过身份验证的加密通道、有界帧、完整性检查和明确配对
  • 建议设置设备密码，及时更新 iOS、iPadOS、macOS 和 Android，并检查所有同步提供方的权限

您的权利与控制

产品分析和营销活动记录均采用假名化标识，并会在 13 个月内自动过期。您可以控制来源权限、本地归因状态、直连配对和导出文件：

  • 访问： 通过 Apple Health 管理 Apple Health 数据，通过 Health Connect 管理 Android 数据，并在您选择的目标位置管理导出文件
  • 权限变更： 通过相关应用或平台控制撤销 HealthKit、Health Connect、提供方、文件、本地网络、通知或配对访问权限
  • 产品分析： 有限的产品事件会按照上文严格的字段排除规则自动收集，并在 13 个月内过期
  • 删除： 请通过对应目标位置删除文件。卸载 Health.md 会删除本地应用状态，但不会删除已经写入文件提供方、已配对计算机、知识库或 API 端点的文件。已提交的分析记录会按照保留策略自动过期。
  • 可移植性： 导出的 Markdown、Obsidian、CSV 和 JSON 文件可以脱离 Health.md 使用
  • 营销活动相关问题： 第一方营销活动记录会在上文所述期限内过期；如有隐私问题或请求，请联系我们

本政策的变更

如果我们的隐私做法发生重大变化，我们会更新本政策，并通过应用更新或网站更新通知用户。本政策顶部的“最后更新时间”反映政策变更时间。
