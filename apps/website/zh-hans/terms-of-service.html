4. 应用功能

Health.md 旨在：

  • 通过 HealthKit API 读取 Apple Health 数据，或通过 Health Connect API 读取 Android 健康数据
  • 将这些数据导出为 Markdown、Obsidian、CSV 和 JSON 文件，并写入您选择的目标位置
  • 按照您设定的计划自动执行导出，但会受到 Apple 后台执行限制或 Android WorkManager 行为约束
  • 在受支持的工作流中，将导出作业直接发送到可选的已配对 Mac 或 CLI
  • 将所选导出直接发送到用户配置的 API 端点

核心健康数据处理在您的设备本地进行。Health.md 不会在 Health.md 服务器上收集或存储健康数据。部分流程会使用由您指定的网络功能或平台服务，包括通过 App Store 或 Google Play 购买/恢复、应用更新、iCloud、Android 文档提供方或第三方文件提供方同步、已配对设备传输，以及用户配置的 API 端点。

如遇医疗紧急情况，请立即联系急救服务。请勿依赖本应用中的任何数据作出有时间紧迫性的医疗决定。
