Export Apple Health to CSV

Export selected Apple Health data to CSV for Excel, Google Sheets, or Numbers. Choose metrics and dates, preview the output, and save it to your own folder.

5 free export actions. Then a one-time lifetime unlock for unlimited exports. No subscription.

Why CSV

The most useful boring format

Use daily totals in Excel, Google Sheets, or Numbers to build charts and compare days. Check the exported Unit column before combining metrics. For source-level records with nested values, choose a CSV-aware analysis tool or export JSON.

Choose your workflow

Export in an app, or convert an XML archive

Apple Health's built-in export produces an XML archive. Conversion tools and scripts can turn that archive into CSV. Other App Store apps also offer CSV export without building a project.

With Health.md, choose your metrics and dates on your iPhone, preview the output, and save it to your own folder. The same export can also write JSON, Markdown, or Obsidian Bases files.

How it works

Metrics, dates, export

1

Authorize and pick metrics

Install Health.md, authorize the Apple Health categories you want, and select exactly which metrics go into the export.

2

Start with one day

Choose Summary for daily totals, select one date, and preview the file before writing it. Once the output fits your workflow, export a longer range.

3

Open it anywhere

Enable CSV, choose a writable folder in Files, and tap Export Data. Review the result, open the folder, and import one generated file into your spreadsheet.

From file to spreadsheet

Open your Apple Health CSV in Excel, Sheets, or Numbers

Try the synthetic CSV sample first, then repeat with one day of your own export. The sample contains fictional values and metadata rows.

Excel on desktop

Use Data → From Text/CSV (under Get Data in some versions), select the file, and check the comma delimiter in the preview before loading. Keep Metric and Unit as text and inspect date conversions. See Microsoft's CSV import instructions. Follow the Apple Health to Excel guide for filtering, combining daily files, and weekly PivotTables.

Google Sheets

Open a spreadsheet, choose File → Import → Upload, and select the CSV. Insert a new sheet and choose Comma if automatic separator detection is wrong. Importing sends the file to Google; try the synthetic sample before deciding whether to upload your records. See Google's import instructions. Follow the Apple Health to Google Sheets guide for combining dates, weekly pivot tables, and charts.

Numbers on Mac

Open the CSV in Numbers. If the columns do not separate correctly, adjust the text import settings and delimiter before editing the table. See Apple's Numbers import guide.

Filter to the Category and Metric you want before charting Value. Keep Unit visible, exclude metadata rows, and do not add daily totals to individual readings. A longer date range produces multiple daily files; do not assume it is one combined workbook.

Check your first file

Verify dates, units, and missing data

  • For daily activity counts, follow the Apple Health steps export guide and keep daily totals separate from source records.
  • Check the Date and Unit columns before combining rows. A distance in meters is not a distance in kilometers.
  • Export Yesterday for an overnight sleep session that started yesterday. Follow the sleep export walkthrough and read how sleep dates are assigned.
  • For exercise sessions, follow the Apple Health workout export guide. Several CSV rows describe one workout; use JSON for per-session identity and grouping.
  • For daily heart statistics or timestamped readings, use the heart rate export guide. Keep bpm separate from HRV milliseconds; use the HRV export walkthrough for SDNN averages and samples.
  • If a metric is missing, check the source data in Apple Health, the selected day, metric selection, and Health permissions. Missing data does not mean zero.
  • If Preview works but writing fails, reselect the destination folder and check that its file provider is available. See the folder troubleshooting guide.

After changing permissions, let your watch or source app finish syncing with Apple Health and try that date again. For a screenshot walkthrough of authorization, Preview, and export results, see your first iPhone export.

The file itself

What's in the CSV

Daily exports write one CSV file per day with the header Date,Category,Metric,Value,Unit,Timestamp. Compatibility summary rows can omit the final Timestamp field; metadata, timestamped, and canonical-record rows use all six fields.

Synthetic example (selected rows). These rows come from the production-generated Apple schema v8 reference fixture, not a person's health data. The full file includes more metrics and metadata.

Download the full synthetic CSV to try an import without sharing your own data. Daily aggregates have no single measurement timestamp. In this example, not_requested means the canonical source archive was off, not that the export failed.

Lossless Health Records adds canonical JSON objects inside CSV cells. Those cells can contain commas, quotes, and line breaks; use a standard CSV importer rather than splitting on commas. See the CSV format reference for the complete row contract and source-record examples.

Privacy

Your data stays yours

Folder exports are local-first by default. Health.md writes the CSV to the folder you choose without creating a Health.md server copy or requiring a Health.md account. If that folder syncs, its provider's terms apply.

The separate, optional single-owner Health.md Cloud pilot retains API exports intentionally uploaded to it. There is no public signup and no automatic device sync. This CSV folder workflow does not upload to that pilot. See the privacy policy for retention, deletion, and the pilot's unbacked storage limits.

Common questions

Frequently asked questions

Do I need a Mac or Xcode to export Apple Health to CSV?

No. Health.md is a shipping iOS app — you choose metrics and a date range on your iPhone and get CSV files back. Nothing to build, no scripts to run, no Mac required.

Which health metrics can I export to CSV?

Choose from supported Apple Health metrics, including steps, heart rate, HRV, sleep, and workouts. Availability depends on your device, OS, source data, and Health permissions.

What date ranges can I export?

Today, yesterday, all available history, or a custom start and end date — per export.

Can I open the CSV in Excel or Google Sheets?

Yes. Start with Summary for daily totals, export one day, and import the CSV into Excel, Google Sheets, or Numbers. Lossless Health Records adds nested JSON cells for source records; use a CSV-aware tool to preserve those values.

Is it free?

The app includes 5 free export actions. One action can include multiple dates and formats. After that, a one-time lifetime unlock removes the limit — no subscription. The App Store shows your current localized purchase price.
