Health data × AI

Put your health data to work with AI.

Two paths from your Apple Health records to an AI assistant: hand it a file, or let it ask scoped questions through Health.md's MCP server.

With either local path, you choose what to share and which client receives it. Connecting local MCP does not enable Cloud uploads.

Two paths

File drop or agent access

1. Export a file, drop it in

Export the metrics and date range you want as CSV or JSON, then attach the file to a Claude Project, a ChatGPT conversation, or your Codex session. The assistant analyzes exactly what you gave it — nothing more.

2. Let an agent ask directly

Standalone direct MCP: healthmd mcp serve runs on macOS, Linux, and Windows as an explicitly unqualified preview, not a qualified stable release. It connects directly to a paired foreground phone without the Mac app. Typed queries require a query-capable iPhone; Android typed MCP queries are not supported.

Legacy bundled Mac helper: The signed healthmd-mcp requires Health.md for Mac installed and open. It queries encrypted Mac context; use a connected foreground iPhone for explicit refreshes and fresh exports. Both topologies return bounded factual results with units, coverage, and explicit missingness.

Both topologies need a local MCP host with stdio support. For standalone, install the CLI, enable Direct CLI Access, and pair with healthmd direct pair over Manual IP or Tailscale. File export works from the iPhone app alone. Read the MCP setup guide

Setup notes

The standalone healthmd mcp serve server runs on macOS, Linux, and Windows as an explicitly unqualified preview, not a qualified stable release. It connects directly to a paired foreground phone without the Mac app. Typed queries require a query-capable iPhone; Android typed MCP queries are not supported.

The legacy bundled healthmd-mcp helper requires Health.md for Mac installed and open. It queries encrypted Mac context; use a connected foreground iPhone for explicit refreshes and fresh exports.

Both topologies need a local MCP host with stdio support. For standalone, install the CLI, enable Direct CLI Access, and pair with healthmd direct pair over Manual IP or Tailscale. Keep Health.md foreground on the phone for each new request. Use native credential storage: Keychain on macOS, an unlocked Secret Service on Linux, or Credential Manager on Windows.

01

Claude

For standalone, configure the absolute installed healthmd path with arguments mcp serve in Claude Desktop's MCP configuration or a trusted Claude Code .mcp.json. For the legacy Mac topology, use the bundled healthmd-mcp path instead. Hosts that negotiate MCP Apps render Health.md's interactive charts inline; text-first clients get exact JSON with image fallbacks.

02

Codex

For standalone, use healthmd setup codex to pair a foreground iPhone and configure healthmd mcp serve. For the legacy Mac topology, register the bundled helper under mcp_servers.healthmd in ~/.codex/config.toml. Restart Codex, then run healthmd_doctor and list metrics with healthmd_metrics. Export and Mac refresh tools stay approval-gated.

03

ChatGPT

Use the file path: export a CSV or JSON of the metrics and dates you want analyzed, then upload or attach it to your conversation. You decide the scope by choosing what to export.

Privacy

Scoped by default

Every request carries its own scope. An agent can only ask about what you approve — queries return bounded pages with coverage, missing intervals, and limitations spelled out, so nothing is silently extrapolated.

Generated-file writes and Mac context refreshes are approval-gated operations, and Health.md reports factual observations only: units, provenance, coverage, missingness. It does not diagnose or recommend treatment. Neither local MCP topology automatically uploads health records to Health.md Cloud.

Local pairing does not authorize Cloud uploads or third-party Cloud reads. The separately authorized read-only Cloud MCP pilot reads retained exports, not a live phone. This disposable single-user VM pilot has no backups or independent security-review sign-off. General production rollout remains unapproved.

Common questions

Frequently asked questions

Which AI assistants work with Health.md?

Local Claude and Codex MCP hosts can use either topology when configured for stdio. Standalone is an explicitly unqualified preview; this is not a hosted-client compatibility guarantee. Any assistant — including ChatGPT — can analyze exported CSV or JSON files you provide.

Do I need the Mac app to use MCP?

No for standalone: healthmd mcp serve runs on macOS, Linux, and Windows as an explicitly unqualified preview, not a qualified stable release. It connects directly to a paired foreground phone without the Mac app. Install the CLI, enable Direct CLI Access, and pair with healthmd direct pair. Typed queries require a query-capable iPhone; Android typed MCP queries are not supported. The legacy bundled healthmd-mcp helper requires Health.md for Mac installed and open. It queries encrypted Mac context; use a connected foreground iPhone for explicit refreshes and fresh exports. Both topologies need a local MCP host with stdio support. File exports work from the iPhone app alone.

Does the agent see all of my health data?

No. Every request carries its own scope — you approve what the agent may ask about, and queries return bounded results with explicit coverage and missingness.

Can Health.md or the AI diagnose me?

No. Health.md reports factual observations with units, provenance, and coverage. It does not diagnose, recommend treatment, or provide medical advice.

Is my health data sent to Health.md's servers for AI use?

Not automatically. Neither local MCP topology automatically uploads health records to Health.md Cloud. Local pairing does not authorize Cloud uploads or third-party Cloud reads. The separately authorized read-only Cloud MCP pilot reads retained exports, not a live phone. This disposable single-user VM pilot has no backups or independent security-review sign-off. General production rollout remains unapproved. You choose which files or query results to share with an AI client.
