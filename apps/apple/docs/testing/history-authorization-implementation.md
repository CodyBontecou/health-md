## Reachable UI and execution

Export's Date Range section is followed by an actionable history-warning card for All Time and explicit bounded ranges. Known limitations intersect when a requested start predates the boundary or the request is logical All Time; unknown/unavailable/failed/unassessed history is never labeled unrestricted. Authenticated expandable details include type, frozen-timezone boundary and dependency attribution. Review Health Access opens the existing Health permissions guide.

One SwiftUI task owns preview assessments; scope, settings, preset, profile and foreground changes invalidate its request. The production coordinator rejects superseded/ABA/cancelled results and requires final scope identity. A replacement phone/tablet preview can wait for the prior physical operation to retire, then perform its own fresh assessment. Admission and assessment share the existing logical deadline; cancellation/expiry removes the waiting request without freeing the physical owner or starting a late replacement. Old results never relabel the new scope. Execution callers keep immediate conservative evidence while the worker is busy. Interactive local/API/Connected Mac export performs independent reassessment after ordinary readiness/quota preflight, then checks the full frozen selection/settings identity before entering existing capture paths. Valid execution evidence takes display precedence over preview evidence; only that evidence carries the rechecked label. Permissions action does not change `canExport`, quota or destination behavior. A slow check has explicit cancel/continue-unverified actions: invalidation releases UI ownership and rejects late completions; continuing stamps `assessment_not_completed`, not a successful empty API result or a rechecked label. Existing readiness/quota is revalidated before capture. No timeout or cancellation-completion guarantee is claimed for HealthKit's underlying async operation.

Interactive iPhone/tablet warning and execution reassessment are implemented. Typed portable queries also produce the independently versioned `metadata.history_assessment` extension through `HealthHistoryQueryCapture`, with Rust client/CLI/MCP readers and scope/cursor binding; this is separate from UI evidence. Phone and tablet execution share the coordination seam, each retaining its own physical worker so repeated cancellation/Continue and retry cannot multiply an unresolved SDK operation. Expiry of the bounded logical wait keeps the explicit Continue/Cancel decision visible; it does not automatically admit an unverified export.

Export admission observations have a separate [version 1 contract](../../../../packages/contracts/export-history/v1/README.md). Direct raw/file producers freeze selected scope before capture, persist evidence with versioned journals, and reject changed/removed evidence on resume. Swift and Rust receivers validate operation/request/peer/calendar/metric authority. Raw responses attach evidence outside the frozen raw-result body; Rust extraction retains it in JSON/JSONL receipts. Generated-file operation receipts preserve it through fresh/resumed/offline recovery. Swift and Rust direct receivers also publish operation-scoped destination sidecars binding each contribution to its actual committed file hash; owner edits and symlinks are preserved/rejected rather than overwritten. Finalized artifact pins prevent internally valid replacement journals from relabelling earlier output. These paths are implemented but production observation advertisement remains disabled pending output and physical qualification.

Receipt propagation into local exports/API bodies and Mac-initiated context jobs remains incomplete. Encrypted Mac context storage now has generation-bound, metric-scoped provenance support: scoped replacement trims old associations, unobserved replacement clears them, and provider changes retain evidence only when the actual Apple content survives. Authenticated producer negotiation and query presentation are not wired yet. Ordinary Shortcuts/scheduled/headless requests still need independent admission evidence. No history assessment enters `HealthData.partialFailures` or frozen daily/archive/raw/SharedSetup data. UI or typed-query assessments cannot backfill another job's receipt. Existing foundations do not qualify these unfinished paths or the complete physical authorization matrix.
