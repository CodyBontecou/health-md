Health.md 3.1 makes export profiles fully editable and scheduled exports far more dependable.

New
• Edit every profile setting in one place — target, destination folder or endpoint, formats, write mode, templates, and metrics — with a system folder picker and inline endpoint creation.
• New profiles start with a quick setup form and warn live when two profiles would write the same files.

Improved
• Profile schedules and the classic schedule run side by side; preserved retries survive interruptions, notification taps resume the exact export, and schedule edits update the next export time immediately.
• Clearer wording when a workout's structured plan can't be read on your device, with copyable partial-export warnings for bug reports.
