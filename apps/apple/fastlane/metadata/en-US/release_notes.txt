Health.md 3.2.1 makes scheduled exports and folder changes more dependable.

Improved
• Schedule Export History now keeps the exact export profile and destination used by each run, including retries.
• Choosing or replacing an iPhone export folder now activates it only after access is saved successfully.

Fixed
• Restarting the app no longer restores an older profile destination after a new local, iCloud Drive, or Dropbox folder was selected.
• If access to a replacement folder is denied, Health.md keeps the previous valid destination instead of disconnecting it.
