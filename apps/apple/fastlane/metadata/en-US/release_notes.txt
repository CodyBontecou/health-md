Health.md 3.1.1 fixes export reliability issues.

Fixed
• Export folders on iCloud Drive, Dropbox, and similar cloud locations no longer lose their selection when the app restarts. Previously the folder had to be re-selected before automatic exports and Shortcuts would run again.
• A completed export no longer shows a red error toast — the success toast is back, with its Preview and Browse actions.
• Choosing the iCloud Drive root now shows it as "iCloud Drive" instead of a technical folder name.
• Scheduled exports targeting an API endpoint with no configured URL now explain exactly what to fix, instead of a generic unknown error.
