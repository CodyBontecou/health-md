# Direct iPhone query protocol v3

The normative capability-gated iPhone query specification lives in the monorepo's language-neutral
contract package:

- [Direct iPhone query protocol v3](../../../../packages/contracts/direct-protocol/v3/protocol.md)
- [Swift v3 reference vectors](../../../../packages/contracts/direct-protocol/v3/fixtures/swift-reference.json)

Query v3 is additive to iPhone application v1 and independent from shared pairing profile v3. New
onboarding uses pairing selector 3 while legacy/trusted compatibility retains selector 1; both lead
to the unchanged authenticated encrypted transport and frame limits. Query v3 enables bounded query requests only when both peers
advertise compatible query capabilities. Status, exports, transfers, resume, and cancellation remain
v1; Android remains v2. This relocation page preserves existing CLI documentation links.
