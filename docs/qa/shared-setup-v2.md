- The v1 contract family is removed from `packages/contracts/shared-setup/v1/` (contracts lane).

- The **default production writers emit `schema_version: 2` exclusively** on both platforms. The earlier standing statements in this record — "the **default portable document writer remains v1** on both platforms" (Status header) and the cycle-6 execution prerequisite "no default production Share action writes v2" — are **superseded as of this decision** and are retained above only as dated history.
- v1-era mappers and tests are removed (`SharedSetupV1Tests.swift`, the v1 codec/mapper symbols). The cycle-2/cycle-4 receipts that counted them (the 25-test `SharedSetupV1Tests` line in the automated-gates table; the transaction-behavior "Bounded versioned document IO" row describing strict integer `1`/`2` dispatch) remain valid history for the trees that produced them and are not receipts about the v2-only tree.
